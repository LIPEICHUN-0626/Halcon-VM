# S114 相机资源与离线采集工作区

状态：代码已接入，部分实现（待集中验证）。图像源模块已在同一参数窗按模式显示本地图片、目录回放、HALCON 相机；示例程序新增离线逐帧采集。真实硬件未连接验收，不能宣称生产级相机能力。

2026-09-28 接线范围：目录回放按图片文件名稳定排序，限定 1–10000 张，成功执行后前进、末尾循环；改变目录/列表会重置游标。相机保存接口名、设备标识与 100–60000 ms 超时，需手动连接；HALCON 打开后尝试设置 `grab_timeout`，接口不支持则明确报错并释放，不自动退回旧图。采一帧及流程运行使用相同源模块，输出托管 Image、逻辑帧 SN、实际来源 Path、宽高、UTC 时间、模式与帧序号，原有下游订阅/结果/日志/方案路径复用。断开、切换方案、删除模块和关闭释放句柄；方案仅保存配置，不保存连接态或回放游标。原本“相机能力尚无入口”只作为此轮前基线。

限制：S114 当时未实现软件触发；S115 已补能力探测与单次软件触发代码，但硬件待集中验证。相机硬件序列号读取、外部硬件触发、多设备同步、掉线自动重连、连续采集和生产级采集队列仍未实现。逻辑帧 SN 不是相机厂商硬件 SN。单个 HALCON 抓图算子在本版不能由 UI 中途取消，超时仍依赖对应采集接口支持。回放例程默认读取本机 HALCON 示例图片目录，实际图片格式兼容性待集中验证。

## A 线：采集任务入口

双击图像源，在同一紧凑参数窗的“常用 / 输入 / ROI / 结果”任务习惯中选择本地图片、离线回放或 HALCON 相机。当前按模式收起不相关字段，相机连接/取图/断开在该模块参数页按需出现；尚未建立集中通讯/资源页的相机总览。图像工作区与原检查器复用真实来源、SN、时间戳及尺寸，不让低频采集选项占满默认首页。

## B 线：真实采集与可重复离线调试

对选定的 HALCON framegrabber 接口建立有界连接、单帧获取和明确关闭，输出原有受管 Image 和类型化 SN/Path/尺寸/时间戳；采集失败不得回退到旧图片。相机配置保存到方案，但运行连接态不自动持久启用；打开方案不擅自连接设备。离线回放复用同一源模块契约，可用固定文件序列或现场记录复现触发/缺图/超时。复用既有调度、配方、复制、ROI/坐标、结果、日志和释放规则，提供不依赖相机硬件的学习示例与模拟失败路径。

硬件接口能力必须以实际安装的 HALCON 版本/接口和可用设备为界，未经设备验证不得声称支持所有品牌相机、同步触发、持续采集或生产稳定性。开发阶段标记“部分实现（待集中验证）”，不逐轮编译/鼠标验收；集中阶段再检查设备打开/关闭、异常/断线、超时、句柄泄漏、保存与恢复。

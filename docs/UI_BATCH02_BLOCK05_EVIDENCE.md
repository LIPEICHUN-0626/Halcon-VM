2026-10-14开发，2026-10-15完成限定验证。复用原S72相邻步骤/执行指针、S73导航轨、S76卡片模式及S77位置/排序历史；不新增图编辑器或执行器，不增加视觉算子，不自动运行、训练、应用或外发。

## 实际改进

- 原默认任务透镜随选中对象折叠无关卡片，自动布局GraphY随之改变，长流程难以保持位置。默认改“固定紧凑”：普通卡72→52 DIP、间距34→24，单击切换不再自动折叠其他卡。“自动聚焦”保留在原更多中的可选模式，不删除有效能力；显式端口展开仍可改变卡高，不冒称任何操作都零位移。
- 卡头只保留序号、实例名、实际结果码及原记录/端口动作。类型和运行说明悬停查看，完整端口按需展开时仍显示类型/状态；原小连接点、细线、参数小窗和图像区未重建。选中边框减轻，未扩大命中范围。
- 将流程栏重复的当前文件显示换为22 DIP高的模块定位框，使用当前流程真实对象、序号/总数和名称。纯数字精确匹配当前步号，名称/工具类型可搜索，空搜索明确无匹配，取消或关列表恢复当前选中。文件路径仍由原源图/队列及图像来源任务呈现。
- 输入搜索引发列表首次打开时，不再由DropDownOpened清掉首个查询；刷新期间事件受保护。列表与当前session/Flow关联，弱实例失效不可用同名/同ID新对象替代。步骤号仅导航序号，不作持久业务ID。
- 原FocusFlowGraphTool异步滚动现在复核最新请求代际、会话、当前Flow、真实弱实例仍在流程及实际选中对象；取消/反选不继续路由。手动相邻导航在运行中暂停原自动跟随，不立即被执行位置抢回；原执行指针定位仍可显式恢复。
- 卡片普通拖动仍只修改Graph坐标；左侧⋮是显式执行排序。原位置完成/撤销重做/保存和输入依赖排序拒绝沿原实现，不用画布位置决定执行。
- 画面复核发现手动重叠布局中，展开端口会被后续卡片盖住。原ContentPresenter按选中/展开提高局部层级，保持用户坐标；不是自动排开所有卡，也不承诺任意手动布局无重叠。

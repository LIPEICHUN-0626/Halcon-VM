# S120 通讯异常恢复与安全重试

状态：A/B 开发路径已写入，部分实现（待集中验证）；无真实 PLC/串口设备验收，也未执行本轮编译、回归或鼠标验收。S117–S119 同样保持待集中验证。

已接入的 A 线：Modbus TCP/RTU 原参数窗按需展开“读取失败恢复”，01–04 可设置额外 0–3 次尝试、0–2000 ms 间隔和 100–120000 ms 总预算；05/06 写入隐藏读取重试项并明确提示不自动重放。结果端口与记录可看 AttemptCount/AttemptTrace；通讯工作区折叠汇总当前方案全部根流程/子流程 TCP、Modbus 任务、目标和当前运行状态，并返回原模块配置。没有新增常驻顶部按钮或第二套配置状态。

已接入的 B 线：Modbus TCP/RTU 只对读取的超时、I/O/Socket 和 RTU CRC 类失败按预算重试；每次重新建事务/串口会话，成功会清除先前尝试错误，写入最多执行一次。普通文本 TCP 不自动重放。三类通讯叶节点均通过后台 I/O 保持界面响应，仍由原确定性流程发布输出；全流程、当前模块和连续试运行受理停止，停止/方案切换/模块删除后的迟到结果不发布。连接阶段轮询停止；读取和发送阶段仍受底层单次超时约束，不能承诺即时中断系统 I/O。

剩余边界：无自动重连的长期设备会话、无写请求幂等令牌/去重、无跨协议统一故障恢复、无真实设备压力/断线验证。通讯列表对子流程与非当前流程只展示配置，不冒充实时状态。当前主题不等于生产可用性认证。

A 线：在现有 TCP、Modbus TCP、Modbus RTU 参数窗和步骤记录中统一显示任务状态、失败原因与最后一次尝试；读任务可按需配置有界重试、退避和失败后人工重试，写任务明确标识“不可自动重放”，不增加常驻顶部按钮。通讯工作区汇总当前方案相关任务及最近异常，能直达原模块配置，而非新造第二套参数状态。

B 线：只对可安全重试的幂等读请求实现有界次数/时间预算/停止保护，避免重复 PLC 写入、重复 TCP 文本外发和无界等待。解决当前同步通讯叶节点阻塞界面导致“停止”无法及时受理的操作问题，且不让并发请求破坏确定性顺序、草稿或结果所有权。每次尝试独立事务或串口会话，保留最终结果及逐次诊断、超时、端口占用和原结果失效语义；显式人工重试重新走原流程执行器。连接断开、方案切换、模块删除和关闭不得留下资源或继续重试。真实设备集中验证前不宣称投产可用。

## 本批实现

- 正式“数值表达式”目录工具，常用页 1 项公式，局部插入菜单分常见公式/数学函数/变量常数；就地显示语法位置或所需 A/B/C/D。输入卡按草稿标明公式需要/未使用，未使用变量无需连接；不增加永久顶部按钮。
- 有界解析器支持常量、A/B/C/D、PI/E、括号、+ - * / % ^，幂右结合且优先于一元负号。支持 14 类函数：abs/sqrt/sin/cos/tan/log/exp/floor/ceil/min/max/pow/round/clamp。角度为弧度、log 为自然对数，round 中点远离零。
- 长度 1024 字符、256 AST 节点、32 层解析嵌套；语法错误指明位置，缺变量、除零、定义域/溢出和非有限值明确失败。只读取公式用到的本周期 Number，不用空值或历史值补 0，不执行任意代码。
- Number / VariableCount / Formula / ResultCode 输出进入既有判定、文本和通讯订阅；沿用原执行器、统一参数草稿、应用、配方、复制/撤销与子流程数值边界。输出默认只显示结果与参与变量数，公式详情按需查看。
- 自带“计算 · 测量偏差与数值公式（无需图像）”五模块示例：数值数组 → 统计 → 偏差公式/极差公式 → 判定。已补中文操作与边界说明；不自动运行、不连接设备或外发。

未做编译、运行或回归，不宣称运算结果、动态输入提示和 UI 已验证。下一 S107 扩展现有 C# / DLL 模块的 Number[] / String[] 输入输出，避免正式数组又退回字符串。

## A 线

逻辑/计算分类提供一个正式表达式工具；统一参数窗常用页只保留公式，函数/变量通过就地插入菜单提供，语法和所需变量就地提示。输入页仅要求公式实际使用的 A/B/C/D，错误指出位置，不让用户为一条公式串联大量简单模块，不新增永久顶部按钮。

## B 线

受限数值表达式支持有限数值常量、A/B/C/D 订阅、括号、四则/余数/幂和常用数值函数，输出 Number 连接既有判定/文本/通讯。解析与求值不执行 C#、不访问文件网络，限制长度、节点和嵌套；变量缺失、除零、非法函数/参数及非有限结果明确失败。沿用原执行器、参数草稿/应用/保存/复制、子流程和中文例程。

它不是任意脚本、不增加第二套变量存储，也不是布尔表达式、向量表达式或完整 VM 表达式兼容声明。集中阶段再验证运算优先级、函数边界、输入失效、草稿保存与学习路径。

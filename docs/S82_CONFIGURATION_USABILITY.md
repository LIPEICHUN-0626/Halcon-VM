# S82 参数配置易用性纠偏

日期：2026-09-01
Git 批次：第 8/10 次，不单独提交或推送

## 用户反馈与代码根因

用户指出点击模块后混乱，参数配置没有海康 VM 那样简单。代码确认并非单纯配色问题：普通单击整张流程卡会启动节点拖动，双击才进入配置；中央外层与被搬入内容各显示一套模块标题；默认同时暴露 6 个字段；编辑模块时 F5 仍按全流程解释。

## 本轮 A 线

- 流程卡普通单击直接打开或切换中央配置，光标改为明确的可点击状态。
- Ctrl 单击继续多选；纵向顺序使用原有专用手柄；低频画布移动改为 `Alt+拖动`。
- 中央工作台删除重复内层身份栏，只显示当前模块、类型、配置/结果状态。
- `常用`默认最多 4 个输入字段，其余统一进入“更多参数”；高级字段校验失败仍自动展开并聚焦。
- 操作顺序固定为“设置参数 → 试运行 → 应用”，未产生草稿时不显示取消/应用。

实体截图：[1366×768 模块配置](../artifacts/s82/s82-module-config-1366x768.png)

## 本轮 B 线

- 中央配置打开时，F5 使用当前草稿只试运行当前模块。实体回归中图像源运行后为 OK，未选择的 OCR 与数值判定仍保持未运行，证明没有误跑全流程。
- 两次点击连接状态优先于普通单击配置。选择来源后点击目标模块主体会自动匹配兼容输入并立即写回真实 `InputBindings`。
- 连接点 38×26 命中区向卡片内收 3 px，减少屏幕缩放和边界取整造成的漏点。

## 验证结果

- `S82ModuleConfigurationUiRegression.ps1`：普通单击、连续切换、无误拖动、单一标题、4 项常用、更多参数、F5 当前模块和实体截图通过。
- `ConnectionInteractionUiRegression.ps1`：实体点击到目标卡、拖接、65% 缩放近点、短连接选择、来源下拉改选和输入页同步通过。
- S76 任务透镜/有限线椭圆、S77 纵向重排/二维码、S79 连接可用性、S81 OCR 与三栏布局回归通过。
- Debug/Release x64 编译和两个版本独立启动通过；未新增永久顶部按钮，未提交或推送 Git。

## 仍未解决

全局“最多四项”只建立了降噪下限，不代表 74 个工具的字段顺序、命名、单位、默认值和控件类型都已完成任务级设计。下一轮必须按高频工具逐项审计，而不是继续把统一长参数表换一个位置。

# S116 设备资源占用与统一入口

状态：代码已接入，部分实现（待集中验证）。S114–S115 的相机连接/取图仍需真实硬件集中验收。

2026-09-28 接线范围：原“通讯”工作区新增默认折叠的相机资源总览，读取当前方案的根流程和嵌套子流程定义，列出接口/设备标识、所属流程/模块、触发与连接态、最近错误；点击定位会安全退出当前内部编辑、切换所属流程/子流程并打开原参数窗，不创建第二套连接按钮或参数状态。展开时和资源变化后刷新，默认首页不增加按钮。

运行态占用：连接前按归一化的 HALCON 接口名 + 设备标识构成资源键，若另一模块已持有同一键，明确拒绝第二次打开，并显示所有者；断开只释放当前 ToolId 持有的句柄。切换流程/方案、配置修改、删除、取图失败仍沿原生命周期释放。相同设备标识在方案内多处配置可保留，但总览提示重复配置，只有一个运行态所有者能连接；因此换流程后仍需显式连接。

边界：`default` 是该接口的默认设备选择，不是硬件序列号。不同 HALCON 接口/别名可能指向同一物理相机，本轮没有跨接口硬件身份确认；不能声称完全杜绝所有物理重复连接。总览是配置和本进程运行态，不是相机枚举、网络设备发现、自动重连或跨进程锁。子流程内相机的连接状态与内部编辑生命周期仍待集中验证。

A 线：在现有资源/通讯工作区按需展示当前方案相机源的设备标识、所属流程/模块、连接/触发状态和最近错误，能定位到原参数窗；默认开发首页不新增永久大按钮，也不复制第二套参数编辑器。

B 线：给实际 HALCON 设备建立稳定资源身份及会话占用约束，跨同一方案的流程/模块防止重复连接与错误释放；切换方案、删除/复制、配置变更和失败后的清理保持明确。保留离线回放用于无相机调试，但不把它冒充设备连接。无硬件阶段仍标记部分实现（待集中验证），最终集中检查锁占用、恢复和真实接口行为。

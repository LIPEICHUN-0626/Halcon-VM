## B 线：真实草稿联动

图像拖动直接写现有四个坐标字段，复用原草稿、当前模块试运行、应用与配方路径。捕获期间限制在图像边界；HALCON 采样仍使用 S92 有效域与双线性邻域检查。Esc 恢复本次拖动前坐标并退出取线；结束取线保留草稿。关闭参数窗或重新载入参数清理取线会话。绿色/橙色端点对应实际采样方向，不创建第二套参数模型。

入口：双击灰度线剖面模块 → 常用 → 图像取线 / 编辑 → 在输入图像拖线 → F5 试运行 → 结果查看曲线 → 应用。

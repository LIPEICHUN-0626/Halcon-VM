# S97 运行准备与输入问题引导

状态：部分实现（待集中验证）。按用户指令，本轮未运行编译、回归、启动或验收。

## A 线

复用原连接问题清单，将其组织为“运行准备 / 输入问题”。区分连接、参数、文件和待运行状态；按问题类型显示“修改输入”或“修改参数”，直接打开统一参数窗及对应输入端口。低频入口仍按需打开，不增加永久工具栏按钮。

## B 线

复用现有参数校验、真实输入绑定诊断和确定性执行计划，在手动范围运行及全流程连续运行开始前识别已知阻断。仅计划范围内的启用模块阻断本次运行，不因范围外的其他模块错误拒绝运行；上游尚无 OK 结果或快照的等待项仍由原执行链处理，不被当成接线错误。图像与显式 Shape 模型路径缺失指向对应参数，准备逻辑不执行 HALCON、脚本、相机或通讯，不修改绑定。

与 S96 来源往返共同组成：运行 → 问题清单 → 原输入 / 参数 → 来源配置 → 返回 → 用户重新运行。未应用草稿仍由原参数窗确认管理，清单读取已应用实例参数。

范围限制：不是完整设备自检、许可证校验、自动根因诊断或全部外部文件扫描；无预先问题不表示运行已通过。相机/PLC 自动触发、批量图片等路径尚未统一接入本轮导航式预准备，不提前宣称覆盖。

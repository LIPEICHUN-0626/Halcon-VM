# S108 数组排序、切片与合并

状态：2026-09-15 首版完整任务路径已写入，部分实现（待集中验证）。两个正式目录入口“数值数组整理 / 文本数组整理”共同覆盖升序、降序、切片、合并和按索引重排，不把每种操作另拆编号。

## 当前用户路径

- 统一参数窗常用页只保留任务选择；切片额外显示起点和数量，最多 3 项。输入页随模式显示 Array、OtherArray 或 Indices / SourceCount；草稿切换不立即写正式连接，应用清除不适用连接，试运行后恢复原参数/绑定。
- 数值按数值排序，文本按 Ordinal 字符顺序；同值保留原先后。切片保序、边界显式校验；合并第一数组在前、追加数组在后。按索引重排要求来源数量匹配，允许明确重复索引，拒绝小数、负数和越界。
- 输出 Array、Indices、Count、SourceCount、FirstCount、SecondCount、Operation、ResultCode，继续供统计、取值、脚本和分支/子流程使用。全部数组独立生成，错误不截断或原地改变输入。
- 默认只看数量/短摘要/任务；结果更多的数组明细增加当前位置、来源索引和值并排，每页 100 项，点击时只读快照。
- 12 模块自带例程“数据 · 数组整理与标签关联（无需图像）”展示尺寸稳定排序、标签跟随、两项切片、标签继续跟随、第二批尺寸/标签顺序合并以及统计/取值。不自动执行或外发，已补中文帮助。

## 索引和容量契约

索引从 0 开始，仅相对本模块直接输入，不是自动累计追溯到最初图像或对象的全局身份。合并以第一数组 + 追加数组为一组逻辑输入，FirstCount 为第二部分起点，SourceCount 为总数量。重排需连接生成索引模块的 Indices 与 SourceCount；关联标签数量一致是必要条件，不是业务身份一致的证明。

空数组可排序、合并或空索引重排；切片允许末尾起点配 0 数量，超出范围不自动缩短。最多 10000 项、文本内容总计最多 262144 字符，合并或重复取值超限明确失败。已有普通同名端口自动匹配沿用，额外来源仍可在输入页明确选择；不宣称所有复杂连接均可一次自动完成。

没有执行编译、回归、运行或鼠标验收，动态草稿/输入、保存与例程均待集中验证。下一 S109 扩展方案全局变量数组和按需值管理；当前 Git 已验证批次仍 6/10。

## A 线

在统一参数窗中以任务模式选择排序/切片/合并，只显示当前模式必需字段；默认结果继续数量/短摘要，原始索引和完整值按需查看。沿用左侧工具目录与自动类型绑定，不增永久顶部按钮。错误应明确数量、索引和类型，而非暴露内部集合异常。

## B 线

提供正式 Number[] / String[] 重组路径，覆盖数值稳定排序及原始索引、保序切片、同类型双数组合并，并能继续进入统计、取值、脚本、分支/子流程和配方。不得就地修改上游数组，索引与排序稳定性明确，空数组、切片范围和总大小限制统一处理；关联标签可依同一索引顺序重排，不能静默丢失对应关系。

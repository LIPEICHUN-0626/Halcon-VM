# S124 平面标定与像素/世界坐标任务

状态：A/B 代码路径已写入，部分实现（待集中验证）；本轮未编译、启动或鼠标验收，不宣称现场标定精度。S123 同样待集中验证。

A 线：从图像工作区选取清晰的像素点与已知实际尺寸/对应世界点，在统一参数小窗形成“采样 → 拟合 → 查看误差 → 应用”短路径；图像叠加点位、编号、异常点和残差，常用参数不超过四项，详情按需展开。保存/重开可恢复标定定义；失效来源时给出直接修复入口，不把一长串矩阵或技术字段默认露出。

B 线：复用 HALCON 的平面 2D 变换能力和现有 Point2D/几何端口，至少支持足够非退化对应点的拟合、每点残差/最大与均方误差、变换方向和单位约定、明确的 ImagePixel → World2D 类型及来源上下文；输出真实世界点/距离供后续测量/判定。拒绝共线/重复/跨图像来源、奇异或非有限变换；配方、复制、撤销、运行、调试、失效和生命周期遵守现有契约。不得仅重命名坐标单位或依赖后台矩阵而无用户操作路径。

边界：先做单相机静态平面与明确参考图像链；不冒充多相机外参、镜头畸变全标定、3D、机器人手眼、硬件同步或现场精度认证。实施前读取实际坐标类型与 HALCON 能力，按现有工具结构落地，不为编号增加空模块。

本轮实际接入：左侧“定位”分类新增“平面标定 / 世界测量”。双击后在统一小窗直接切到当前模块输入图像取点；确认点 ROI，输入对应世界 X/Y，逐点加入草稿（同一 ROI 再加入会更新快照）。3–64 个同源、非重复、非共线点使用 HALCON `vector_to_hom_mat2d` 拟合；列表显示逐点残差，图像叠加点号、异常残差标记和反投影残差线，首屏展示 RMS/最大值，矩阵留在结果详情。点击原参数窗“应用”才进入配方/撤销路径。输入页必连明确 Image，PointA/PointB 可选；两点俱全时用同一变换输出 WorldPointA/B 和 `WorldDistance:Number`，可连接数值判定。WorldPoint2D 与 ImagePixel Point2D 使用不同端口类型和坐标身份；旧像素测量工具不能误订阅世界点。来源切换、点越界、未运行、重复端点、退化/非有限/近奇异及下游失效按真实执行路径拒绝。

坐标约定：像素 `Column, Row` 作为本工具的数学输入 `(x,y)`，通过用户填写的对应点映射到世界 `X,Y`；该矩阵只供点坐标转换，输出端口特意命名 `PixelToWorldMatrix`，不能直接复制给 HALCON 图像/Region/XLD 变换。HALCON 对 iconic 数据的矩阵行列与像素中心约定不同，详见 [20.11 官方 vector_to_hom_mat2d](https://www.mvtec.com/doc/halcon/2011/en/vector_to_hom_mat2d.html) 和 [affine_trans_point_2d](https://www.mvtec.com/doc/halcon/2011/en/affine_trans_point_2d.html)。世界单位由用户显式输入（默认 mm），残差和距离同单位；红色异常点为相对本次 RMS 的提示，不自动删点。样本保存的是加入时的坐标快照，不随 ROI 后续移动自动更改。

仍缺标定板自动识别、镜头畸变/内参、跨相机外参、世界坐标形状工具与现场标准件精度验证；当前仿射结果不是完整相机标定。

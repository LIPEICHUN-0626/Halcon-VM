# S127 标定板采样与相机内参求解

状态：A/B 代码已接入，部分实现（待集中验证）；S126 也待集中验证。

原“镜头畸变校正”统一参数任务中按需展开“标定板多图求参”，不新增默认顶部按钮。用户选 HALCON `.cpd/.descr` 描述文件，加入最多 64 张图像；队列可移除、重新加入，选中可查看缩略图，逐张显示检测标记数与失败原因。图像路径、板文件路径保存在配方作重新求参依据，但运行校正只依赖已应用的内参数值；跨机器缺失的样本不会静默改变既有运行结果。

求参需先提供已知的焦距、像元尺度、主点和分辨率初值。后台使用 HALCON `create_calib_data`、`set_calib_data_cam_param`、`set_calib_data_calib_object`，逐图 `find_calib_object`/`get_calib_data_observ_points`，有效样本至少 6 张，再用 `calibrate_cameras` 与 `get_calib_data(..., 'camera', 0, 'params')` 获取优化内参和重投影 RMS。失败图像保留诊断，混尺寸/缺失/重复路径不计入样本；显示标定板中心覆盖提示。求得数值和 RMS 只填入 S126 草稿，原“应用”才写方案并供校正运行，下游可查看 RMS/样本数输出。切换模块或修改样本会取消/丢弃旧异步结果。没有伪造标定板检测，也不宣称现场精度认证。

边界：目前支持单相机 `area_scan_division` 与 HALCON 描述文件。样本图像/描述文件路径非随行资产，缺失时需要用户重新定位；未做生产现场误差验证、畸变点/ROI 显式迁移或多相机/手眼标定。HALCON 依据：[标定数据对象](https://www.mvtec.com/doc/halcon/2011/en/set_calib_data_calib_object.html)、[标定板检测](https://www.mvtec.com/doc/halcon/2011/en/find_calib_object.html)、[相机求参与 RMS](https://www.mvtec.com/doc/halcon/2011/en/calibrate_cameras.html)。

A 线：在原图像与统一参数任务内提供标定板图像队列、单张检测状态、姿态覆盖/失败原因和简明质量摘要；失败图片可就地删除或重采，不在默认首屏显示长参数矩阵，不增加永久顶部按钮。

B 线：基于 HALCON 真实标定数据模型和标定板描述文件，从多张明确来源图像求相机内参并保存为 S126 可直接复用的相机资源；检查模型、图像尺寸、采样数量、分布和数值条件，输出重投影误差与失败诊断。不得把 S124 平面仿射、单张手输内参或伪造标定板检测冒充相机内参标定。若标定板资源/实图不可用，保留用户可加载真实图片和描述文件的操作路径，记录尚待现场验证的边界。

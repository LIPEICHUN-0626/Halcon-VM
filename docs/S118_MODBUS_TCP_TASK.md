# S118 Modbus TCP 工业设备任务

状态：A/B 代码已接入，部分实现（待集中验证）。S117 的 TCP 文本交换与字段映射不冒充 Modbus 协议；本模块独立构造和校验二进制 MBAP。

A 线已写入：在原工具目录“通讯”分类下提供可直接添加的 Modbus TCP 任务；双击进入同一参数窗，主机/端口、功能、Unit ID、零起始 PDU 地址与读数量/写数值紧凑呈现，并按读写切换字段。超时与本地示例帧收起，不加默认顶部按钮。结果页有首值/数量/异常码/耗时画像，步骤记录子页面显示本次通讯摘要。

B 线已写入：功能码 01/02/03/04/05/06，一次连接/一次请求并释放，事务号、协议号、长度、Unit ID、功能码、读字节数、写单点回显和异常帧严格核对；线圈/离散输入最多 2000 位，保持/输入寄存器最多 125 个，地址和 Unit ID 有界。输出首值 Number、完整 Number[]、位状态 Boolean、异常码/诊断/耗时/结果码；写 05/06 可用本地值或上游 Number，已绑定而无值不回退本地。参数进入原配方/复制/草稿与结果日志；切回读功能时清除写入绑定。离线生成/解析响应只用于学习，不联网、不发布流程结果。

边界：地址为零起始 PDU 地址，不输入 40001 之类展示编号；寄存器是原始无符号 16 位值。当前无 32/64 位跨寄存器编码、字节/字序选择、批量写、多次轮询、自动重连、设备发现、加密鉴权或真实 PLC 验收。当前读写是同步单次操作，停止只能在连接/收发边界观察，不能保证即时中断操作系统阻塞调用。开发阶段不逐轮编译/验收，因此不能宣称已运行通过。

协议依据：[Modbus Application Protocol v1.1b3](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf)、[Modbus TCP Messaging Guide v1.0b](https://modbus.org/docs/Modbus_Messaging_Implementation_Guide_V1_0b.pdf)。

## A 线：分支结果的统一配置与学习路径

“逻辑 / 计算”目录加入“分支结果选择”。双击仍打开原紧凑参数窗，常用页仅选结果类型，输入页配置选择条件、真路径值、假路径值，结果页显示实际分支、值与来源结果码。支持数值、文本、布尔、图像、区域和轮廓六类，不添加永久顶部按钮。

变更结果类型只修改草稿并重新提供兼容来源；应用/取消、试运行、复制、配方与撤销复用原路径。图像输入及关联图像按实际选中分支解析，条件尚未有效时明确提示全局图像不是分支结果。

原真/假条件示例扩展为：自带图像与判定 → 通过时滤波 / 未通过时增强 → 分支图像选择 → 汇合后亮度统计。由用户主动载入，不自动运行。中文帮助解释两条路径与后续输出，不改变空白启动规则。

## B 线：真实选择与结果所有权

- Boolean 条件决定读取 WhenTrue 或 WhenFalse；只要求被选中的端口有效，未选中分支可跳过。
- 真实类型化 Value 输出可连接后续模块；声明类型同时作用于两输入和输出端口。
- Image / Region / XLD 创建独立受管快照，不借用上游对象所有权；标量严格匹配类型，数值拒绝非有限值。
- 条件或选中分支缺失、禁用、顺序不合法、类型不符、异常、跳过或释放时明确报错；不使用旧值，不自动切换备用路径。
- 保留 SelectedBranch / SelectedSource / SelectedResultCode 和真实日志。选择操作成功不覆盖整个流程中原有 NG。
- 普通工具依赖跳过仍按 S100 处理；只有本工具真/假数据输入免于未选中路径的跳过传播。自身执行条件和 Selector 仍遵循原规则。

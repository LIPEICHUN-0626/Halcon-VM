## 已写入的用户路径

- 逻辑/计算分类增加“数值数组生成”“文本分割为数组”“数值数组统计 / 取值”“文本数组取值”。生成类常用 2 项（本地文本、字面分隔符），取值类 1 项（从 0 开始的索引）；不增加永久顶部按钮。
- 可订阅上游 String，未绑定才使用本地文本；来源失效不回退。正式数组内部独占数据，外部不能修改底层数组；分支和子流程复制独立值。
- 数值统计输出 Count、SelectedValue、Min、Max、Mean、Sum、Index；文本取值输出 Text、Length、Count、Index。灰度线剖面新增真实 Samples Number[]，沿原 HALCON 采样顺序传递，不改采样算法或旧端口。
- 数组摘要仅显示数量与前 3 项短值；结果“更多 → 数组明细”每页 100 项，只读点击时快照，不自动排序或裁剪实际数据。
- 统一参数模型持久化文本/分隔符/索引，沿用配方、复制、撤销与草稿试运行路径。例程“数据 · 数组统计与报文组装（无需图像）”包含 6 个根模块和统计子流程，示范数组 → 子流程均值 → 判定，以及 String[] → 工位字段 → 报文；不自动运行、不外发。

## 明确契约与剩余范围

最多 10000 项、文本输入/文本数组内容最多 262144 字符；字面分隔符 1–16 字符，不是 CSV/正则/转义解析器。整段空文本生成空数组，连续分隔符保留空字段；数值项使用 InvariantCulture 小数点格式，拒绝空项、非法数值、NaN/Infinity。取值/统计拒绝空数组、越界和求和溢出，不静默截断或过滤。文本保留空白/空项。

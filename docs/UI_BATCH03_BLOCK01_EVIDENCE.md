## A：原参数窗内减少误操作

固定参考区域仍在原紧凑小窗，不挤压流程或图像。采集按钮不再横向铺满，改为“采为固定参考 / 更新固定参考”；缺图、缺定位、未应用模板或输入来源草稿有变化时不可点，并就近显示下一步，禁用按钮仍可悬停查看原因。这里仅查看已有输出，不读图、不制作模型、不运行上游；实际采参考仍执行原坐标、模型版本、图像范围和编辑租约检查，不把按钮可用当生产资格。

参考默认只显示“尚未采集 / 参考待应用 / 参考已应用”和尺寸；坐标、角度、版本放到悬停说明。输出范围收为190DIP短选择框；原双视口入口明确为“查看对齐前后”。没有新增永久工具栏或第二配置状态。

修正三个真实状态问题：

- 输出范围/插值改变时，立即按当前可见选项使旧对照失效，不再等待其他刷新；验证、应用与预览统一读SelectedItem.Tag，避免SelectedValue事件时序。
- F5临时挂载草稿后，恢复已应用参数再刷新参考状态，避免把尚未应用的参考显示成“已应用”。
- 撤销输入草稿后，等原输入行和dirty标志恢复再刷新；采集/对照恢复原资格，不留下旧“先应用输入”提示。

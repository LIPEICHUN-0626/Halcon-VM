# S126 相机内参与畸变校正

状态：A/B 代码已接入，部分实现（待集中验证）；S125 世界点复用测量同样待集中验证。

已接入“图像处理 → 镜头畸变校正”正式工具。统一参数小窗的首屏只显示导入 HALCON 相机参数 `.dat`、来源/模型/尺寸摘要和固定尺寸/尽量保留视野选择；8 项已知内参手填收在“更多”折叠中。导入后将数值而不是原文件路径写入配方，草稿应用、撤销/重做、保存沿用原路径；原图像区的输入/输出双画面可对照校正前后。输入页要求显式 Image 来源，不允许隐式全局图像。

B 线仅支持 HALCON `area_scan_division` 面阵除法模型，读取 `.dat` 或用户已知 Focus/Kappa/Sx/Sy/Cx/Cy/Width/Height；执行前检查有限值、正焦距/像元尺度、图像类型与分辨率。使用 `change_radial_distortion_cam_par` 将径向畸变设为零，再用 `change_radial_distortion_image` 生成受管 Image。输出保留模型、来源、视野模式和原/校正图上下文；校正图坐标身份包含相机数值、模式和输入链的指纹，内参或来源变化后旧 ROI 不会误当作同一图像链。HALCON 在边缘超出原图时会产生无效域，未把缺失像素伪装成有效测量。未实现标定板自动求参、其他镜头模型和精度认证。

HALCON 算子语义依据：[径向畸变参数变更](https://www.mvtec.com/doc/halcon/2111/en/change_radial_distortion_cam_par.html)、[图像畸变校正](https://www.mvtec.com/doc/halcon/2111/en/change_radial_distortion_image.html)、[读取相机参数](https://www.mvtec.com/doc/halcon/2111/en/read_cam_par.html)。当前仓库绑定 HALCON 20.11；这些代码待集中编译和实图验证，不以文档代替运行证据。

A 线：在现有图像/标定任务中提供紧凑的相机模型与校正前后视图、来源/分辨率/单位摘要，复用统一参数小窗和图像视口，不增加默认顶部按钮或长矩阵首屏。

B 线：用 HALCON 的真实相机标定/畸变映射路径建立可保存、可重用的内参资源和校正图像输出；校验输入图像尺寸、相机模型、资源身份与 ROI 坐标，明确不同于 S124 平面仿射。校正后的 Image 要有独立图像链身份，可驱动下游视觉工具。若没有可用标定板或现场采样条件，先完成可由用户输入/导入已知相机参数的真实校正路径，再将自动标定板采集标为后续缺口，不以伪造参数凑编号。

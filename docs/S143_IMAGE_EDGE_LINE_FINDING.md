## 本次实际接入（2026-10-04）

原测量分类新增 `ImageEdgeLineFindingS143`，统一小窗只露极性/阈值/采样数/搜索半宽四项，其余沿原单一更多参数。`MainWindow.S143.UI.cs` / 原测量域编辑复用端点/整体/半宽拖动、草稿与原上下文清理，几何独立 `IsEdgeLineS143`，不改变旧 MeasurePairs；法向 `(dcol,-drow)`（行/列）与 `phi=atan2(-dr,dc)-π/2` 相同，换端点改变实际方向但不偷偷换极性。缺正式 Image 不预览旧图；忙碌拒绝。F5 和原模块上下文显示绿色质量保留点、红色质量拒绝点与橙色未采到中心；逐采样位置/幅值/残差/原因按需在 Samples 端口查看。不是新常驻工具栏或第二套草稿。

`ImageEdgeLineServiceS143` 实际 MeasurePos 单边采样和原 FitXldLines 的 Tukey/Huber 拟合，byte/uint2/real 单通道及 byte RGB（明确 rgb1_to_gray），不缩放高位原值。每个窗口加保守双线性余量先检查真实域；像素舍入重复中心不凑有效点，最大200采样、1600万像素/边长16384。先鲁棒拟合，再按显式残差规则筛点并复拟合/复核，跨度由真实点投影而非字符串计算；未找到清 MainLine/角度/长度/残差，不补零。质量拒绝是本工具门槛，不冒充 HALCON 内部鲁棒权重。

正式输出 HasLine、Line2D、EdgePoints/KeptPoints/RejectedPoints/MissingSamples Point2D[]、XLD、数量/覆盖/方向/残差和参数，保持真实图像坐标，可进入既有点线/线线/点集/数值判定；原端口类型/草稿/复制/撤销/保存/保护与临时对象释放路径复用。首版明确不支持本地/继承ROI、屏蔽、位置修正，非法配置拒绝，不显示虚假模式。中文版正式工具帮助和“示例程序→测量·图像边缘找直线”可编辑方案已接入，不自动运行/预造成功，需在真实图上把搜索带放到直边；Coverage 示例阈值只供学习。

算子支持与 domain/插值边界依据 [HALCON 20.11 MeasurePos](https://www.mvtec.com/doc/halcon/2011/en/measure_pos.html) 和 [GenMeasureRectangle2](https://www.mvtec.com/doc/halcon/2011/en/gen_measure_rectangle2.html)，不是运行通过证据。上方只有已保存开发路径，没有编译/交互/精度结论；下方保留起始缺口与集中验证合同。

## 真实代码缺口与复用边界

`Models/VmToolModels.cs` 的正式目录已有卡尺边缘对、线性多卡尺、圆周找圆、XLD 直线拟合和类型化点集直线拟合，没有从 Image 直接提取单边并得到可复用直线的入口。`MainWindow.xaml.cs` 的 `RunLinearCaliperArrayTool` 实际调用 HALCON `MeasurePairs`，输出宽度统计和字符串索引，不输出 Line2D/Point2D[]；不能改个名称就称为找直线。`RunXldLineFittingTool` 须先订阅 XLD，部分轮廓还需分段；`RunCircularCaliperCircleFinderTool` 已有 `MeasurePos` 单边采样思路。

复用原统一参数小窗、`MainWindow.S83.cs` 的任务常用档案、阵列搜索域图上编辑结构和 `Services/HalconImageService.cs` 的真实 `FitXldLines`；输出沿原 `VmLine2D`、`VmPoint2DArray`、托管 XLD 与同链坐标约定进入已有点线/线线测量。复用是操作和基础算法复用，不解析旧卡尺字符串、不复制第二套草稿或执行器。

## A 线：画搜索带即可找线

原左侧“测量”分类新增正式“边缘找直线”工具及搜索别名；仍单击选择/拖动、双击统一小窗，不修改流程宽度、缩放或节点位置，不增加永久顶部按钮。`常用 / 输入 / ROI / 结果` 四页与原草稿、应用、撤销、F5 当前模块保持同一状态。

默认常用最多四项，优先边缘极性、阈值、采样数量和搜索半宽；起终点在输入图像上设置，显示窄基线、搜索带和清晰法向箭头，可移动、改端点、调带宽，数值细节及平滑/拟合/有效覆盖/残差门槛进入一个“更多参数”。极性按图上搜索方向解释；改变端点或方向不得默默翻转用户的边缘选择语义。技术解释以短提示/悬停显示，不常驻算子长文。

输入页明确正式 Image 来源，绑定无效或上游未运行先提示来源问题；不能为了预览回退到活动旧图。ROI 页解释本模块搜索带与图像有效域，不把训练框、普通全局 ROI 或别的图像链混用。若接入统一检测/屏蔽或位置修正，必须真正执行并保留同链守卫；未支持的模式明确拒绝，不能只放可选按钮。

F5 只运行当前草稿模块。结果首屏显示找到/未找到、有效采样数、方向和残差；采点、失败/拒绝点与拟合线按需查看，编号/失败原因进入明细。缺线没有零角度、零端点或旧线；几何找到不等于产品尺寸合格，产品容差由明确下游判定完成。切换图像/模块或关闭小窗清理搜索编辑和调试图层，不串上下文。

## B 线：本次单边采样与真实类型化直线

正式必需 Image 订阅使用本次有效输出与明确 ImagePixel 坐标身份，不读取 `currentImage`、历史图或字符串坐标。沿搜索基线有界布置法向测量矩形，真实 HALCON `GenMeasureRectangle2 / MeasurePos` 采单边；多边候选使用明确、确定性的选择规则，并显示该规则与箭头含义。采样数量、几何尺寸、搜索带、迭代、输出数量和诊断文字都有上限，复制前拒绝无穷/NaN、零长度和非法参数。

采样须符合真实图像边界及有效 domain；越界、缺边和被屏蔽采样保留明确原因，不把无效域当完整图。支持的像素/通道与灰度策略依据既有真实 HALCON 路径明确，禁止为适配显示偷偷将高位图归一化成 byte；不支持的输入明确失败。新工具不改变原边缘对测宽或圆周找圆语义。

对真实采点调用既有 HALCON 鲁棒直线拟合，检查有限结果、最少有效点、基线跨度/覆盖和配置残差条件，拒绝集中在短段的虚假稳定直线。采样点序、方向和拟合线端点采用固定约定；鲁棒拟合产生的拒绝/残差必须来自真实数据，不靠绘制一条基线冒充检测。采样失败、拟合不足和质量门槛不满足分别明示。

正式输出至少有 `HasLine` Boolean、`MainLine` Line2D、`EdgePoints` Point2D[]、托管 `XLD`、有效/失败或拒绝数量、覆盖、方向、长度和平均/最大残差，以及参数/ResultCode。几何结果保持真实源图像链，像素长度/残差标为 px，方向标为度；不得允许用户填 mm 冒充标定。只有真实有效直线才发布 MainLine，失败或未找到清除旧几何，缺失数值不补零。EdgePoints 与采样明细同序、异常点有来源索引；若分别输出采到点和拟合保留点，命名必须明确，不混称。

有效直线可直接订阅到原点到线距离、类型化双直线关系/交点等工具；点集可进入原点集统计/拟合，不要求用户重新解析文本。数值可接原数值判定和正式生产结果项。模型参数、绑定、搜索几何进入方案/复制/撤销/恢复/工程随行，稳定 ToolId 引用按原契约处理；无训练模型文件，不新增虚假资源依赖。

单次测量句柄、HTuple、图像副本、XLD 在成功、NG、异常、停止、重复运行、删除、切换及草稿退出均有唯一拥有者与释放路径。原工程授权/lease、忙碌保护和原执行异常诊断保持，不新建后台常驻模型或无界采样任务。

# HALCON 工业视觉平台用户手册（中文版）

> 版本状态：S78 首版。本文档描述当前实际软件，不代表尚未实现的规划能力。完整逐模块输入、输出和操作步骤也可从软件顶部 `帮助 -> 中文版帮助手册` 查看；该目录由当前代码中的真实模块元数据生成。

## 1. 软件定位

本软件是以 HALCON 为视觉算法内核的工业视觉流程平台。产品信息结构和操作习惯参考成熟工业视觉平台，但使用自己的界面、名称和视觉资产。当前支持本地图像、图像处理、检测分割、轮廓处理、测量、定位、识别、逻辑计算、TCP 通讯及受信任 C#/DLL 脚本。
本软件活动页面不使用 VM / VisionMaster 品牌。。

## 2. 主界面

- 顶部：方案、图像输入、流程运行、停止、运行界面和低频命令。
- 左侧：单一分类入口的模块箱；支持搜索、分类、收藏、最近和流程片段。
- 中央：自上而下的真实流程顺序与数据连接。
- 右上：当前图像、模块输入/输出、ROI 和结果图层。
- 右下：运行结果和按需任务入口。
- 中央配置：双击流程模块后打开；使用 `常用 / 输入 / ROI / 结果` 四个短标签切换。
`运行界面` 是页面切换，不会自动开始检测；执行操作使用 `运行流程`。`打开图像` 只改变调试输入，不会自动运行。

## 3. 快速开始

1. 从顶部 `示例程序` 选择一个学习方案，或新建方案。
2. 在左侧模块箱搜索工具，双击或拖入中央流程。
3. 通过顶部/底部端点或中央配置的 `输入` 页连接真实数据来源。
4. 双击模块，在 `常用` 页先设置最多 6 个关键参数；其余参数按需展开。
5. 涉及检测区域时在 `ROI` 页绑定检测区、屏蔽区或位置修正。
6. 点击 `试运行`，同时检查右上图像叠加、`结果` 页和模块卡的 `记录`。
7. 点击 `应用` 写入当前配方，再运行完整流程并保存方案。
参数页中的长技术说明默认不占用页面。把鼠标停在按钮、参数组或选项上，会显示浅色悬浮解释。

### 模块连线与改选来源

- 从来源模块的底部圆点拖到目标模块，松开即可；也可以先点击底部圆点，再点击目标模块。目标不必精确点到小圆点。
- 连接成功会立即完成输入绑定，不需要另外再绑定一次。流程区显示“输入绑定”栏，直接在来源下拉框中重新选择即可生效。
- 之后点击连接线可重新打开绑定栏；“详情与操作 → 全部输入”打开中央输入页，查看该模块的全部输入。
- 只能订阅类型兼容、已启用的前序输出；连错对象会显示原因，不覆盖旧连接。按 Esc 取消正在建立的连线，Ctrl+Z 撤销已经完成的绑定修改。

## 4. 示例程序

顶部 `示例程序` 当前提供：
- 入门 · 基础分割与区域测量：图像源 -> 灰度 -> 滤波 -> 阈值 -> 形态学 -> 面积筛选 -> 轮廓测量 -> 数值判定。
- 识别 · 二维码与结果输出：图像源 -> 二维代码识别 -> 文本组装 / 数量判定。
- 测量 · 亚像素轮廓与直线拟合：图像源 -> 灰度 -> 亚像素边缘 -> 轮廓平滑 -> 直线拟合 -> 残差判定。
示例使用本机 HALCON 20.11 示例图像；若本机没有对应文件，流程仍会完整装载，但需在第一个图像源中换成自己的图片。示例不会自动执行，且必须另存后才能成为正式方案。

## 5. 模块配置

### 常用

只显示当前模块最常用的关键参数，默认最多 6 项。点击 `展开高级参数` 后才显示低频设置。

### 输入

显示每个输入端口的数据类型、来源工具、来源端口和当前值。必需输入未连接、来源位于下游、类型不兼容或来源停用时，模块会明确等待或报错。

### ROI

绑定检测 ROI、屏蔽区、模板或位置修正。屏蔽区会从有效检测域中真实扣除；图层显隐只影响显示，不改变算法输入。

### 结果

显示最近一次试运行或流程运行的输出、ResultCode、耗时和异常。应用配置后会使当前模块及下游旧结果失效，必须重新运行。

## 7. 调试、图像与结果

- `当前` 只运行选中模块；`全流程` 按确定性顺序运行全部启用模块。
- 断点在模块执行前命中；单步只执行一个启用模块。
- 停止、暂停和超时在工具步骤之间生效，不能中断正在执行的单个 HALCON 算子。
- 图像区 `选择图形 / 平移图像 / 适应窗口` 分别控制编辑、浏览和显示比例。
- ROI、Region、XLD 结果图层的显隐和排序不改变算法输出或 InputBindings。
- 模块卡 `记录` 打开该步骤的日志与通讯交互。

## 8. 方案与安全边界

- 方案保存流程顺序、连接、参数、ROI、资源引用及界面配置。
- 未应用的模块草稿和未保存方案在切换、打开示例或退出前都会确认。
- Image、Region、XLD 和模型句柄由平台管理生命周期；旧结果在重跑、删除或切换方案时必须安全释放。
- 相机 SDK、完整标定/坐标、多流程/子流程、权限部署及生产设备协议仍属于后续差距，不应在当前验收中写成已完成。

## 9. 常见问题

- 模块显示“待连接”：打开中央配置的 `输入` 页，检查来源、类型和顺序。
- 模块返回 NG：先看 `结果` 页和步骤 `记录`；NG 可以是正常业务判定，不一定是软件异常。
- 图像没有叠加：检查当前图像上下文、图层显隐和生产者是否已在本周期运行。
- 参数改了但流程没变化：确认是否点击 `应用`，并重新运行当前模块及下游。
- 示例图像缺失：在第一个本地图像源中选择自己的图片。

## 10. 中央配置工作台的完整操作

双击流程中的模块卡，或从模块卡的上下文菜单选择配置，中央区域会切换为该模块的任务工作台。这里编辑的是同一个真实模块实例，不是参数副本或独立弹窗。标题区会显示模块名称、所属类别和当前运行状态；右上角 `?` 可直接打开该模块的中文帮助。
推荐按以下顺序完成一次参数调整：先在 `输入` 页确认数据源，再到 `ROI` 页确认坐标和检测范围，然后在 `常用` 页只修改影响结果的关键参数，最后执行 `试运行` 并在 `结果` 页核对。试运行成功不等于参数已保存，必须点击 `应用` 才会写入当前方案。需要放弃本次草稿时使用 `取消`；需要回到上次应用状态时使用 `撤销`。按 `Esc` 或关闭按钮可返回流程画布，尚未处理的草稿会先给出提示。
当参数数量较多时，页面不会把全部选项同时展开。高频参数位于第一屏，低频设置放在高级区域或选择项中。输入框应使用合法单位和范围；红色边框表示当前值不能用于执行。对于枚举项，优先从下拉列表选择，不要手工猜测 HALCON 操作符字符串。

## 11. 图像、ROI 与坐标使用原则

在图像区创建 ROI 前，先确认当前显示的是模块真实输入，而不是经过缩放、旋转、裁剪或透视变换后的输出。不同坐标系的 ROI 不能直接混用。软件会尽可能隔离不兼容叠加，但工程人员仍应在位置修正或几何变换后明确选择正确的数据链。
检测 ROI 用于限制计算范围；屏蔽区用于从检测范围中排除不需要的区域；图层显隐只控制观察效果。矩形、旋转矩形、圆、椭圆、圆环、多边形、线和点具有不同用途，线和点不能作为面屏蔽区。锁定 ROI 可以防止现场调试时误拖动；停用 ROI 会改变执行输入，隐藏 ROI 则不会。
双画面适合比较模块输入与输出。开启联动后，两侧按归一化中心和可视比例同步，不代表两幅图拥有相同像素坐标。使用透视、仿射、裁剪、旋转或缩放工具后，应依据模块输出的偏移、比例或变换矩阵解释测量结果。

## 12. 运行界面与生产使用

`运行界面` 面向操作员查看检测状态，它与开发界面共享当前正式方案和真实执行器，但隐藏流程编辑、参数修改、ROI 编辑和调试命令。进入运行界面不会自动开始检测；可选择单次、连续、暂停或停止。图片批次可按当前、选中或全部范围执行，运行卡会显示当前项目、OK/NG、耗时、良率和报警。
现场使用前应完成三项检查：正式方案已经保存；所有外部输入和通讯目标可用；停止条件、超时和遇 NG 行为符合设备节拍。连续运行中不要修改方案文件或替换模型资源。需要调整参数时先停止运行、回到开发界面、保留原方案备份，再通过试运行验证并保存为新版本。
异常与 NG 必须区分。NG 是工具正常执行后得到的不合格判定；异常表示输入、参数、资源、HALCON 调用或通讯失败。生产统计可以包含 NG，但不能把异常当作正常良率样本。步骤 `记录` 中应保留执行时间、输入摘要、结果码和异常原因，便于追溯。

## 13. 配方保存、恢复与交接

示例程序、临时调整和新建流程在首次正式使用前必须执行 `另存为`。文件名应能识别产品、工位和版本，不建议覆盖仍在生产的旧方案。状态栏的未保存标记消失后，才表示流程顺序、连接、参数和 ROI 已写入磁盘。
打开方案时，平台会校验版本字段、工具种类、输入绑定和资源引用。旧方案可以在兼容范围内迁移，但迁移成功不代表所有外部文件仍存在。Shape 模型、脚本 DLL、本地图像和其他资源应与方案一起交接，并在目标电脑上重新执行自检。
软件维护单份恢复副本和备份用于应对意外退出或写入中断。恢复副本是故障保护，不是版本管理。重要投产版本仍应进入项目的正式文件管理或 Git 仓库，并记录 HALCON 版本、相机配置、标定数据和验证样本。

## 14. 故障排查顺序

遇到问题时建议按固定顺序处理，避免同时修改多个变量：
1. 检查当前方案、运行模式和选中图像是否正确。
2. 从第一个异常模块向上游查看，确认所有必需端口已有本周期有效值。
3. 在模块 `结果` 页读取 ResultCode、耗时和异常；再打开步骤 `记录` 获取完整上下文。
4. 检查 ROI 是否越界、有效域是否被屏蔽区全部扣除、图像通道和尺寸是否满足工具要求。
5. 对模型、DLL、HDevelop 文件和本地图像确认路径存在，并确认部署电脑可读取。
6. 只试运行当前模块；成功后再运行到所选或执行全流程，确认下游没有使用旧快照。
7. 若问题只在 Release 或独立启动出现，记录软件版本、HALCON 版本、方案和复现图片后再交给开发人员。
不要通过反复点击运行来掩盖偶发异常。相同输入和参数应产生可解释的确定性结果；任何不稳定现象都应保存原图、方案、日志和发生时间。

## 15. 当前版本验收边界

当前版本已经具备较完整的本地图像流程、Region/XLD 处理、测量、Shape 定位、二维代码、类型化几何、脚本/DLL、TCP、配方、调试和运行页入口，但仍不是成熟工业平台的终点。相机厂商 SDK、完整标定与坐标体系、子流程和多流程调度、真正多画面、资源中心、权限审计、部署工具、设备级协议和长期稳定性验证仍需后续迭代。
因此，验收某项能力时必须沿着 `工具入口 -> 参数配置 -> 输入 -> 执行 -> 输出/图形 -> 记录/异常 -> 配方保存 -> 独立验证` 逐项检查。只有内部类、数据结构或没有用户入口的代码不能算产品功能；只有按钮、页面或说明而没有真实算法执行也不能算完成。

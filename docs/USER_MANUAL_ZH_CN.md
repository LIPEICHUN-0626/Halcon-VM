# HALCON 工业视觉平台用户手册（中文版）

## 帮助页快速定位（2026-10-22）

帮助正文上方“本页”下拉可直接跳到实际的输入、输出、操作顺序或其他章节；选“概览”回首标题。切文章会重建本页目录，搜索无结果时不显示旧章节。它只滚动帮助，不打开模块、不执行或改变参数。参数窗打开时，“当前模块帮助”仍对应正在编辑的模块，不随普通单击的另一节点串换。

当前操作要点：只有唯一兼容组合的连线才自动绑定，多组合请明确选择；普通阈值支持检测ROI/屏蔽及输入有效域交集；F5在参数窗内试当前草稿，关闭参数窗后遵循顶部所选运行范围。应用会清除旧输出，请重跑本模块再继续下游，不把草稿试运行当正式配方已生效。

## 三条学习路径与直接选步骤（2026-10-21）

打开顶部“示例程序”，首层直接选择“检测入门 · 对象计数与判定”“定位应用 · 模板对齐后测边”或“测量应用 · 标定与实际距离”。其余原示例仍在五个分类中。装载不会运行、训练、采参考或标定，原未保存修改仍须确认。

学习窗顶部短下拉可以直接选择步骤，不必展开说明找目录。选择或上/下一步只换提示，不替换正在编辑的模块或草稿；点击“打开当前模块”或具体的“配置模板/固定参考/标定”才打开对应原任务。技术边界放在悬停和“说明”中。示例缺本机图片时，请选择自己的真实图片。

修改参数时依次“F5试草稿 → 应用 → 重新运行”，再继续下游；应用会清除旧输出。图像源对应“选择图片 → F5预览 → 应用 → 再读一帧”。临时步骤号不会保存成完成状态；重开工程按实际模块继续配置，不自动恢复旧输出或学习导航。

本轮已验证检测示例的真实对象/面积数组/条件灰度与保存；定位、标定示例已验证前提入口、类型订阅及配置保存重开，整条算法结果尚未由本轮证明。见 `UI_BATCH02_BLOCK09_EVIDENCE.md`。

## 工程编辑、运行界面与当前流程（2026-10-21）

“运行界面”只换页面，不开始检测，也不切换流程；左上“工程编辑”返回配置页面，原执行状态保持。运行页方案卡单独显示当前流程名称，运行按钮悬停也会显示完整名称。“当前流程运行一次”只执行这条流程；连续与暂停/继续在右侧“运行控制”里，顶部保留单次和停止快捷入口。

工程页流程下拉框决定当前编辑/运行的流程。切换会保留各流程配置，清空所切入流程的图像、旧输出和当前周期状态，不恢复以前的运行对象；已有周期记录仍在。请先完成或停止运行、通讯触发、后台学习或工程迁移，再切换流程；未应用草稿仍按原确认处理，不会自动应用。

“最近流程结果”是工程与运行页共用的最近一次范围执行结果，不等于新生产周期。“流程统计·含工程运行”累计当前根流程完整执行，包含工程页完整运行，不包含单模块F5、子流程调试或离线通讯模拟。只切页面不会改变原周期记录的页面/流程来源；正式生产周期和值仍按原周期记录筛选及“当前周期结果”的资格显示。自定义卡片标题保留，技术含义可悬停查看。

## 按当前模式填写参数（2026-10-18）

滤波、增强、通道、差分、透视和数值运算只显示并读取当前模式需要的字段。局部增强的窗口宽/高与因子、透视显式输出的宽/高、四舍五入的小数位数直接在“常用”页填写；低频四点坐标等仍在“更多参数”。像素字段标注 px，允许范围和技术含义悬停查看。

输入不合法时，当前字段出现红框，常用页就近说明范围；常用字段错误不会自动展开其他高级设置。修改或取消草稿会清除提示。窗口尺寸或半径填 0 会明确提示错误，不偷偷替换成默认值。

切换模式不会自动应用或运行。当前不使用的字段不会阻挡试运行，也不会写入正式配置；切回原模式后仍可继续编辑这份未应用草稿。“试运行/F5”临时使用当前模式参数，“应用参数”才写入配置，“取消修改”恢复已应用参数。应用后可用原撤销/重做；方案保存的是已应用配置，不是尚未应用的文本。

## 查看结果和下游输入（2026-10-16）

对象分析“结果”页默认显示对象数、选中面积、中心位置和同序面积数组。模板匹配显示匹配数、选中分数、位置和位姿。位置采用X=列、Y=行（像素），坐标来源身份在悬停说明中查看；缺选保持无值，不自动取另一个对象。

在下游“输入”页选好来源后，可直接点“查看数组…”或“查看点集…”。它们显示当前来源的只读快照，不会修改绑定或运行模块；数组沿用从0开始的索引，点集明细沿用原显示序号，异常项保留供诊断。窗口打开后不会随上游重跑改变，查看新值请关闭后重新打开。

“草稿预览”不代表参数已应用；“来源未标注”需要重新运行确认；“暂无有效值”表示保留了连接但上游尚无可用结果。最近执行值仍须通过实际下游的参数、模型及坐标检查。只打开输入页查看不会标记为修改；真正换来源后，F5可试运行草稿，“应用参数”写入配置，“取消修改”恢复已应用来源。

## 长流程定位、卡片和移动（2026-10-15）

默认“固定紧凑”卡片只显示序号、实例名、结果码、原记录/端口入口和一行订阅摘要。选中模块不再自动折叠其他步骤；类型/运行说明悬停查看，双击才打开原参数小窗。需要自动折叠无关步骤时，在流程“更多→卡片”选择“自动聚焦”，它只改变显示，不改执行与配方；该可选模式会改变模块的显示位置。

流程按钮下方是模块定位框，显示当前“序号/总数·名称”。输入纯数字精确找当前步号，或输入名称/工具类型筛选，再选择要定位的模块。没有匹配会提示，关闭列表恢复当前模块；定位只选中和滚动画面，不运行或开参数。步号随显式排序改变，不是业务ID。原Alt+↑/↓可检查相邻步骤，Alt+Enter定位执行指针；运行中手动检查其他步骤会暂停自动跟随。

拖动卡片普通位置只移动画布坐标，不改变执行顺序或订阅；左侧⋮才是显式执行排序入口，不能把消费者排到来源之前。坐标编辑支持原撤销/重做和方案保存。手动摆放允许模块相互重叠；展开端口会提到前面方便查看，收起回紧凑卡，不擅自移动其他模块。要重新纵向排列，可明确使用原更多中的自动布局，它不改变执行顺序。

当前已做40模块非接管专项，不代表任意规模、所有DPI/缩放、实体拖动/键盘焦点和草稿确认全部验收通过。

## 模块连接与改选来源（2026-10-14）

从上游底部小点连接下游顶部小点，也可以先点来源，再点目标。只有一个兼容组合时直接绑定；多个同类型输出或输入时，原连接小栏显示中文“来源含义→目标输入含义”，点击你需要的一项。比如图像源既有宽度也有高度，连接数值判定时应明确选择，不由软件猜一个。悬停查看具体模块、端口名与类型。

小栏只临时显示在流程区，不缩小原布局；选择期间收起旧绑定检查栏。关闭或Esc取消本次选择，原绑定保留。选择不取图、不运行或自动应用其他草稿，图像/模型与正式运行结果仍需明确配置和执行。

连接后点卡片订阅摘要或连接线，在“输入绑定”中直接改选来源；下拉显示中文含义与正式端口名，旁边说明兼容数量。选择立即修改正式订阅，可撤销/重做并随方案保存，目标和下游旧输出失效，需要重新运行。只提供启用的前序同类型端口，无效旧来源保留提示但不可选；同一双输入模块不能把同个上游端点同时用作两项输入。未运行模块也可用于搭建连接，候选存在不表示当前已有有效结果。

运行中、编辑授权过期或模块被删除/替换时旧选择不会应用；停止后重新选择。参数有草稿时仍走原明确确认，不默默覆盖草稿。实体拖接/确认窗及全部缩放设备组合尚未全面验收。

## 图像源、回放列表与当前帧（2026-10-14）

双击图像源，在来源方式选择本地图片、目录回放或相机。选择文件/目录只进入草稿，不取图、不应用；点击“读取一帧”或F5才按当前草稿读图。完整路径在更多中编辑，默认只显示文件/目录短名，悬停查看完整路径。SN留空时随实际读取的文件名生成，已有自定义SN不被文件选择覆盖。

当前输出条显示最后真实Image的文件名、帧位置、尺寸及实际方式，区分草稿F5帧/已运行帧；切换相机草稿不会把此前回放帧称作相机帧。悬停查看真实路径、SN和帧时间。应用会清旧输出，需要明确重读，不把当前所选路径当作已读图。

回放模式先应用目录，再展开“回放列表 · 选择下一次读取”。展开仅扫描原队列文件名，不解码图像；选择列表项只调整本模块下一次位置，不取图、不修改配方。F5读取所选帧并进入下一张，到末尾回首张；顺序按文件名。目录/模式有未应用草稿时列表选择禁用，但F5仍可试读草稿。列表属于当前模块，不按名字替代另一模块；运行忙碌时不能改下一次位置。

保存保留文件/目录、方式等正式配置，不保存运行图片、相机连接或回放指针。重开是无输出状态，回放从首帧开始，必须明确取图；文件/目录失效时显示无有效帧，不补旧图。相机仍须用户明确连接，不因选模式、打开参数或重开方案自动连接。

## 模板制作、试运行与应用（2026-10-14）

图像源的Image可以直接连接Shape或NCC，不需要独立模板制作模块。双击匹配模块，在制作区明确读取已应用的图像来源，再框选目标并点击“制作草稿模板”。读取不会顺便应用其他参数；Image来源还有草稿改动时，应先明确应用输入，再读取。新模板为独立版本，旧正式模板不被覆盖。

制作完成后预览收起，常用页露出最低分数/最大匹配数，并显示“新模板草稿 · 待应用”。F5试草稿，确认结果后点击应用，再明确重跑得到正式结果。取消修改返回已应用版本；草稿匹配结果不能作为已应用模板的选定位姿使用。普通同步参数F5遇到错误会在结果/状态区说明，不额外弹确认窗；其他独立操作仍保留原提示。

Shape的名称、明确训练ROI和模型文件管理在更多中。不会默认挑选已有ROI训练；读取新图后必须重新框选。加载.shm只进入草稿，导出已应用模型仅保存独立副本，不改变当前资源路径。NCC制作/应用语义相同，模型路径和SHA在悬停查看。旋转范围必须由实际模型覆盖，整周模型保留360°搜索，不通过静默裁剪掩盖有限模型越界。

## 灰度阈值与检测区域（2026-10-13）

图像源可直接连接灰度阈值。双击阈值模块，在“常用”设置灰度上下限，短摘要显示当前范围；“ROI”页直接勾选检测区/屏蔽区，不用展开更多。点击“在图像区画矩形”只开始原图像区的矩形绘制，不自动应用参数或展开旧侧栏；其他形状仍从图像区 ROI 菜单选择。位置修正与批量操作留在更多。

未绑定ROI时只分析输入图像已有有效域。绑定本地检测区后，检测区合并、扣除屏蔽，再与输入有效域取交集；同图像链前序Region也可作为继承来源。普通阈值采用合并检测域，不支持逐ROI独立执行；纯屏蔽区不能单独作为运行域。旧未标注图像来源的ROI按原兼容语义保留，建议在当前图像重新绘制。

缺失检测区会保留一个“缺失ROI”勾选条目，请取消后重新选择；已绑定的跨图像ROI也可以先解绑，不允许跨源重新勾选。本地检测区全部停用、绑定失效、跨坐标或域交集为空时会拒绝运行，不把全图或旧Region/Area当成本次结果。继承策略下，本地检测区不参与计算，只使用前序Region并扣除已启用屏蔽区。F5试当前草稿，确认后应用并保存；应用或改范围后需明确重跑下游。常用页估算暗/亮目标仍使用已应用ROI，建议数值只进入草稿。

## 帮助与快速学习（2026-10-13）

“帮助”打开中文版原帮助中心，首页只保留添加、连接、配置、试运行、看结果、保存六步。完整示例与工程说明保留在“学习示例与完整项目”等章节，首页链接可直接查看，不运行或修改方案。目录下拉框可选全部目录、操作入门或模块参考；搜索可用模块名、用途及真实端口类型，多个词以空格分隔。没有匹配时会提示缩短关键词或切换目录，×清空搜索但不切换当前目录。

参数窗内的当前模块帮助以正在编辑的模块为准，不因普通选中其他节点串模块；主界面则以选中模块为准。同一帮助窗口重复定位当前模块，关闭后再打开，不堆叠窗口。完整学习项目的当前一步默认收起说明，按钮明确标为“模块帮助”；上/下一步只改变学习导航，不自动运行或把当前步骤标成通过。

## 新建、打开与学习示例（2026-10-13）

启动始终是空白方案，不自动打开最近工程或模板。可以从左侧模块箱添加工具，也可以点击空白流程里的“打开方案…”或“学习示例”。学习按钮只展开顶部原有示例分类，选择具体示例才装载，不自动运行、训练或采集。

“文件 → 最近方案”显示最多8个最近路径；同名文件可悬停查看完整路径，缺失文件不可点击，记录仍可在原方案诊断页移除。打开方案先选文件，再处理当前未应用参数和未保存方案，取消文件选择不提前放弃当前内容。未保存提示中的取消会保留当前方案和尚未处理的恢复副本；主动确认应用或放弃草稿则仍遵循原参数提示。

示例也是可编辑方案，先按步骤配置并主动运行，再用“保存方案”选择自己的路径；需要独立副本时用“文件 → 方案另存为”。首次保存仍需自己确认位置。任务运行、批次、通讯触发或后台学习未结束时不能换方案/示例，请明确停止并等待退出；不会自动强停任务来切换。

## 步骤记录与通讯查看（2026-10-13）

点击模块卡“记录”，在独立只读窗看本步骤状态和记录，不遮住流程。取消“跟随最新”只冻结查看，不停止运行或记录采集；搜索过滤快照，刷新快照不会执行。复制当前页选中内容，未选中时复制当前页；文本导出保存当前查看快照而非全部历史。

步骤历史只显示具有精确会话/流程/模块身份的最近200条根记录，旧纯文本仍在全局日志，不按名字猜归属。每页最多256Ki字符，达到上限会说明。通讯页的离线模拟标注依据实际输出，查看不会连接或发送，普通连接输出不代表持续在线。删除实例或来源身份失效后请重新打开记录。

## 运行范围与停止（2026-10-13）

流程区“选中模块”只运行所选节点的已应用参数；“当前流程”按顺序运行当前流程全部启用步骤，不运行方案内其他流程。F5的范围在流程区提示：参数窗打开时试运行编辑模块草稿，关闭后运行或继续当前流程。主窗口输入框焦点不会提前屏蔽F5。

Shift+F5与停止任务按钮请求原停止路径，包括停用TCP触发、取消训练、停止连续/批次；等待安全边界，不强行中断HALCON。任务忙碌时先明确停止并等待退出，再选择其他运行范围，不自动切换或应用草稿。暂停的父流程不会被参数窗F5接管。

## 查看结果（2026-10-13）

默认结果区显示真实关键端口值，全部端口与细节在“更多”。“最近草稿试运行”不等于已应用参数结果，“最近模块执行”不等于整流程合格；未知来源不冒称生产。应用或输入/ROI变化后旧值、旧耗时清空，需要明确重跑。

“异常”表示实际执行错误，应根据红色原因处理；不要把它当作产品业务NG。输出类型或数值无效会明确提示，不能靠日志摘要替代结果或把无值当0。本轮尚未完成所有异步/子流程来源标记或全类型审计。

“原图 / 对齐图”使用现有双画面查看左原图、右真实重采样图。输出 Image、Region 有效域及参考坐标的 AlignedPose；源图 ROI 不自动迁移到对齐坐标，在对齐图另配检测 ROI，或显式把有效 Region 接同链下游 ROI。双线性会保守排除输入域边界/孔洞旁一像素，身份变换也减少边缘；最近邻不采用该支持收缩。支持单张 1/3 通道 byte/int2/uint2/real，最多 16777216 像素；无位姿、跨链、无效数值或空域明确失败，不保留旧图。旧 Shape 位姿仅在此消费者中兼容转换，不宣称现场精度。示例“图像·定位后对齐”为 Source→NCC→对齐→灰度统计，统计同时订阅对齐 Image 与有效 Region；不自动制模板、取参考或运行。参考版本随方案保存，显式复制核对并迁移依赖身份，不重新采参考。

S131 NCC 灰度模板匹配（部分实现，待集中验证）：从定位分类添加 NCC，直接连接图像源 Image。双击原参数小窗，展开“制作模板”并“读取输入”；已经连接的图像源可在这里读取，其他处理类上游须先运行。输入绑定草稿变化须先应用，不会取图时偷偷提交；搜索参数不强制先应用才能制作/F5。在窗内拖动至少 3×3 的整数像素矩形框选有纹理目标，后台制作独立模板，新版本只进入草稿，失败/取消/来源版本变化不覆盖旧已应用模型。训练矩形须完整在实际有效域，最多 1048576 像素；输入为单张单通道 byte/uint2、最多 16777216 像素，RGB 须显式上游转灰度。

常用仅最低分数和最多候选；角度/重叠/极性/层数在“更多参数”。训练框不是搜索区，默认全图；ROI 页的搜索区/屏蔽只限制模板参考点位置，不保证整个模板足迹在 ROI 内。改层数/极性须重训，角度范围不得超出已训练范围。F5 查看最佳分数、数量、真实像素 Point/Pose 和候选框；结果“更多”可选候选并显示十字，只查看不改变下游最佳位姿。无匹配 MatchCount=0、HasMatch=false、NG，Score=0 是无匹配哨兵而非真实相关分数，不发布位置/位姿/框；10 秒搜索超时等异常不会当作零匹配或复用旧结果。Score 可接数值判定，Point/Pose 可供同坐标下游；模板可跨图匹配，训练来源是历史身份不自动重映射。模型 `.ncm`/SHA 及元数据随草稿/方案保存、复制、撤销，迁移用打包导出；每次句柄独立释放，旧资源保留给恢复但尚无自动清理。显式示例“定位·NCC 灰度模板”提供 Image→NCC→分数判定，需用户主动框选制作，不自动训练/运行；缺少本机 fabrik.png 时自选单通道图片。

S130 良品变化缺陷检测（部分实现，待集中验证）：在检测/分割分类添加模块，连接已对齐的单通道 Image 并先运行上游；双击打开原参数小窗，常用为最小灰差、波动倍数和最小缺陷面积三项。展开“良品样本与训练”，每次不同良品采集后点击“加入当前输入良品”，或确认外部照片为良品且按当前输入对齐后多选加入。图像和原始有效域复制为受管资源，至少 3 张、最多 64 张；单张最多 16777216 像素、总样本最多 268435456 像素。点击“学习良品”后台逐张检查并产生独立新模型草稿，再“应用”；F5 可按原草稿试运行路径检测。失败/取消不覆盖原已应用版本，停止/关闭/切换拒绝过期结果；取消须等待当前 HALCON 算子完成。检测 ROI 必须完全在所有样本共同有效域内，RGB 须上游显式转灰度，只接受 byte/int2/uint2 且同尺寸，不自动对齐或缩放。结果看缺陷 Region、面积/比例/数量，Area 接数值判定，Region 接区域筛选/轮廓；RawArea 为筛选前差异，执行 OK 不代表产品合格。源/相机标识/上游处理或 ROI 几何变化须重建样本，单改检测容差无需重学。普通保存保留受管路径，迁移电脑用打包导出，模型、共同有效域和全部样本会包含。独立句柄在每次执行后释放，旧文件保留给撤销/恢复，尚无自动清理；未解析嵌套来源复制仍须重采样。显式示例提供“输入→检测→轮廓、面积判定”四步，不自动训练，不伪造已对齐良品集。

S129 HSV 颜色检测（部分实现，待集中验证）：在检测/分割分类添加模块，连接图像源的 RGB Image 并先运行上游。双击模块，常用页点击“图像取色”，再单击模块输入图像；只更新色相草稿，Esc 取消。常用四项为色相/容差/饱和度下限/亮度下限，上限在“更多参数”；红色跨 0° 自动环绕。ROI 页复用本地/继承/合并及屏蔽，改来源后须先应用。F5 只试运行当前模块，结果看掩膜、覆盖比例和区域数；AreaRatio（百分比）接数值判定，Region 接区域面积筛选。零匹配返回 0% 与 HasMatch=false，执行 OK 不等于产品合格。byte RGB 按 255、uint2 按 65535、real 必须为 0–1；不自动按图片拉伸。比例分母为 domain∩有效 ROI/屏蔽，不是外接框。低饱和/暗点不直接取色，黑白灰可手填容差 180°，限制 S/V 范围。应用并保存；示例程序→检测·颜色取样与覆盖比例可显式加载四步学习流程，不自动运行，未找到本机示例图片时须自选 RGB 图片。

本软件是以 HALCON 为视觉算法内核的工业视觉流程平台。产品信息结构和操作习惯参考成熟工业视觉平台，但使用自己的界面、名称和视觉资产。当前图像源代码路径支持本地图片、目录逐帧回放及 HALCON 相机显式连接/单帧采集，并支持图像处理、检测分割、轮廓处理、测量、定位、识别、逻辑计算、TCP 通讯及受信任 C#/DLL 脚本；相机硬件路径尚待集中验证。

S114–S115 图像源：双击图像源，在参数窗“常用”选择本地图片、目录逐帧回放或 HALCON 相机。回放按文件名排序，每次运行读取下一张、末尾循环；折叠的“故障/节拍模拟”可按每 N 次请求缺图或过快请求报错，不读图也不复用旧输出。相机填写本机已安装的 HALCON 接口名、设备标识（可留空使用 default）、自由采集/软件触发及超时，先“应用”，再“连接”；软件触发只有设备公开对应能力才可连接。每次“采一帧”只运行当前源，“运行流程”才驱动下游。连接/采集错误不会回退旧图，断开、删模块、切换方案和退出会释放连接；重新打开方案不会自动连接。结果端口提供 Image、逻辑帧 SN、实际来源、宽高、UTC 时间、帧号、采集耗时和触发模式；逻辑 SN 不代表厂商硬件序号。参数窗“采集诊断”和选中源时图像区的一行状态可看上次错误并直达配置。学习入口：示例程序 → 采集 · 离线逐帧回放。真实相机软件触发尚待硬件验证；外部硬件触发、相机同步及掉线重连尚未完成。

S116 设备总览：在右侧“通讯”工作区按需展开“相机资源与占用”，查看当前方案所有流程及子流程中的相机源、接口/设备标识、运行态连接所有者和最近错误。点击“打开配置”返回原图像源参数窗，不会自动连接或取图。相同接口和设备标识在本进程内只允许一个模块持有连接；其他配置可保留，换流程后须重新显式连接。`default` 不是硬件唯一编号，不同接口可能指向同一相机；这一层软件锁不等于跨进程硬件锁，仍待真实设备集中验证。

S117 TCP 响应字段：双击 TCP 客户端流程工具，常用区配置主机/端口、发送模板和是否等待响应；I/O 页订阅模板变量。按需展开“响应字段映射”，选择分隔字段或 JSON 路径，分别为文本、数值、布尔值填写字段索引/路径；空白项不出现对应输出端口。分隔索引从 0 开始，数值使用点号小数，布尔接受 true/false/1/0；JSON 值须与目标类型一致。勾选等待响应，运行后在原结果页查看本次原始发送/接收及映射输出；缺字段或类型不符会给 NG 和具体原因，不使用旧值。可在折叠的“无设备试解析”粘贴样本验证当前草稿，不联网、不发布结果。编码和行尾已收进“传输格式”，超时仍在“更多参数”；尚不是 Modbus 等工业协议。

S118 Modbus TCP（部分实现，待集中验证）：在左侧“通讯”分类添加“Modbus TCP 读写”，双击模块打开紧凑参数窗。填 PLC/网关主机和端口（常见 502）、功能 01/02/03/04 读或 05/06 写、Unit ID 和零起始 PDU 地址；读时填数量，写时填本地值或在“输入”页订阅上游 Number。不能直接把设备手册的 40001 展示编号填作地址；须确认厂商从 0 还是从 1 标注。读位最多 2000，读寄存器最多 125。运行当前模块或流程后，“结果”页查看首值、数量、异常码、耗时，更多端口可供下游订阅；模块“记录”子页面有本次通讯摘要。折叠的“超时与离线学习”可生成示例响应或粘贴十六进制帧试解码，不会连接设备或发布输出。寄存器类型/字序解码已由 S122 续接；真实 PLC 仍待集中验收。

S119 Modbus RTU 串口（部分实现，待集中验证）：在左侧“通讯”分类添加“Modbus RTU 串口读写”，双击后选 COM 口、01–06 功能和零起始地址，读时填数量，写时填本地数值或在“输入”页绑定上游 Number。展开“串口细节与离线学习”确认波特率、站号、校验位、停止位和响应超时；默认是 9600、8E1、站号 1，实际参数须按设备手册改。串口仅在运行时打开并释放，口被占用、CRC 错、站号或回显不符会返回 NG 和诊断，不保留旧结果。结果与模块“记录”可查看首值、数量、异常码、耗时；离线示例帧不打开串口。S122 已补共用寄存器解码；不支持广播写、RS-485 自动方向、自动重连或真实设备验收。

S120 读取失败恢复（部分实现，待集中验证）：Modbus TCP/RTU 参数窗展开“读取失败恢复”，对 01–04 读取设置额外尝试次数、间隔和总预算；默认不额外重试。05/06 写入最多只发一次，TCP 文本发送也不自动重放。运行后在结果/模块记录看尝试次数和逐次错误；右侧“通讯”工作区按需展开“方案通讯任务”可查看目标与最近状态，并返回原模块。运行时停止可在通讯等待期间受理，但底层发送/读取受单次系统超时限制，不保证毫秒级立即中断。无真实设备验收，不建议未经现场测试直接用于 PLC 写入。

S121 离线模拟（部分实现，待集中验证）：双击 TCP/Modbus 模块，在原参数窗勾选“离线模拟”，展开原“离线响应样本”或“超时与离线学习/串口细节与离线学习”填入样本文本或十六进制响应帧；可先点“生成示例帧”，再应用草稿并运行当前模块或流程。结果页出现 `IsSimulation=true`，TCP 显示接收文本及字段映射，Modbus 显示原始请求/响应帧、首值、数组与诊断，可继续接数值判定。模拟期间不打开 TCP/COM；包含模拟的流程禁止真实通讯、相机、脚本和全局变量写入，且结果不会自动/手动作为真实结果外发或写入生产最近记录/批次追溯。切回真实模式须重新应用，默认旧方案仍为真实设备。模拟成功不能证明现场设备连接与时序可靠。

S122 寄存器解码（部分实现，待集中验证）：Modbus TCP/RTU 选择 03/04 读寄存器后，在原参数窗选主值类型 U16/I16、U32/I32/F32 或 U64/I64/F64。多寄存器类型才出现“高字在前/低字在前”，读取数量至少为 1/2/4；主值取当前地址起的前 N 个寄存器，其余原始值仍在 `Values`。离线“解析帧”会显示原始字到主值；运行后 `Value` 是可准确表达的 Number，`DecodedText` 是精确主值文本，结果首屏展示类型/字序摘要，完整原始字和帧在“更多”。64 位整数超出双精度精确范围时只给文本，不向 Number 下游发布近似值。字序须按设备手册明确选择，不支持字节交换或工程缩放；未经现场设备验证。
S124 平面标定 / 世界测量（部分实现，待集中验证）：从左侧“定位”加入工具，把图像源连接到 Image。双击模块，在“常用”点“图像取点”，到图像上单击并确认点 ROI；填写该点实际 X/Y 后点“加入选中点 ROI”，重复至少 3 个分散点。列表和图像显示点号及拟合误差；红色异常点只提示，不自动删除。满意后点参数窗“应用”并保存方案。输入页可再绑定同一图像链的 PointA 与 PointB，运行后结果页查看世界点、世界距离、RMS/最大残差；世界距离可接数值判定。点移动后需重新加入更新快照，换图像来源会拒绝混用。当前仅静态平面仿射标定，不等于镜头畸变、3D 或现场精度认证。

S125 世界点距离 / 方向（部分实现，待集中验证）：在左侧“测量”加入工具，双击后到“输入”页分别选两个 World2D 点。输入卡显示单位和标定来源；两个点必须来自同一标定版本和图像链，单位相同，不能拿像素点混接。运行后“结果”页看世界距离、方向角和单位，完整输出还含 X/Y 偏移和世界中点。需要尺寸 OK/NG 时，把 `WorldDistance` 接到“数值判定”的 `Value`，在判定工具设置上下限。混源时先在输入页重选，必要时打开上游“平面标定 / 世界测量”修改单位或重新运行。世界中点可继续作为 World2D 点订阅；此功能不是畸变校正或现场精度保证。

## 9. 常见问题

- 模块显示“待连接”：打开参数小窗的 `输入` 页，检查来源、类型和顺序。
- 模块返回 NG：先看 `结果` 页和步骤 `记录`；NG 可以是正常业务判定，不一定是软件异常。
- 图像没有叠加：检查当前图像上下文、图层显隐和生产者是否已在本周期运行。

## 10. 参数小窗的完整操作

单击流程模块只选择，按住拖动可移动位置；双击模块卡，或从上下文菜单选择配置，会打开统一参数小窗。小窗可拖动和调整大小，原流程宽度、缩放和节点位置不变。这里编辑的是同一个真实模块的配置草稿，不是另一套配置。单击其他模块不会替换窗内编辑对象；双击其他模块才切换，并先处理未应用草稿。标题显示当前配置模块；`帮助` 打开这个模块的中文说明，`F5` 只试运行窗内模块。

### 从图像源制作一个匹配模板（S89 开发中）

参数窗打开期间，图像区的“当前模块输入/输出”、双画面输入和模板候选定位也跟随窗内模块。单击其他流程卡不会切走正在调试的模块图像；关闭参数窗后恢复跟随流程选择。“全局输入”和历史图片不受这项规则替换。

1. 添加本地图像源与模板匹配，连接图像源的 Image 输出到模板匹配的 Image 输入。
2. 双击模板匹配，在“制作模板”区域点击“读取输入图像”。该动作应用当前输入设置，只读取已连接的本地图像源，不运行整条流程；若上游是处理模块，先运行该上游。
3. 在窗内图像上按住鼠标框选目标。预览为灰度，框选使用原图像素坐标；框选尚未保存。
4. 点击“制作模板”，成功后得到受管 HALCON 模型。训练范围不自动成为搜索范围；没有指定搜索 ROI 时默认搜索全图。

   再次制作会保存独立模型版本，不覆盖之前的模型；训练失败时继续保留原模型。再次双击同一模块不会清除正在框选的范围。关闭或切换时，如果框选尚未制作，会提示确认放弃；选择取消可返回继续制作。
5. 按 F5 或“试运行当前模块”，在结果页看分数、位置和轮廓；可把 Score 连接数值判定。确认后保存方案，交接时一并保留模型文件。

常用页优先显示最小分数和最大数量；模型名称、已有训练 ROI、角度和尺度等进入更多参数。图像更换后需要重新读取和框选；过小框选或无有效特征时应修正范围，不能把失败当作新模型已制作成功。
推荐按以下顺序完成一次参数调整：先在 `输入` 页确认数据源，再到 `ROI` 页确认坐标和检测范围，然后在 `常用` 页只修改影响结果的关键参数，最后执行 `试运行` 并在 `结果` 页核对。试运行成功不等于参数已保存，必须点击 `应用` 才会写入当前方案。需要放弃本次草稿时使用 `取消`；需要回到上次应用状态时使用 `撤销`。按 `Esc` 或关闭按钮可返回流程画布，尚未处理的草稿会先给出提示。
当参数数量较多时，页面不会把全部选项同时展开。高频参数位于第一屏，低频设置放在高级区域或选择项中。输入框应使用合法单位和范围；红色边框表示当前值不能用于执行。对于枚举项，优先从下拉列表选择，不要手工猜测 HALCON 操作符字符串。

## 11. 图像、ROI 与坐标使用原则

在图像区创建 ROI 前，先确认当前显示的是模块真实输入，而不是经过缩放、旋转、裁剪或透视变换后的输出。不同坐标系的 ROI 不能直接混用。软件会尽可能隔离不兼容叠加，但工程人员仍应在位置修正或几何变换后明确选择正确的数据链。
检测 ROI 用于限制计算范围；屏蔽区用于从检测范围中排除不需要的区域；图层显隐只控制观察效果。矩形、旋转矩形、圆、椭圆、圆环、多边形、线和点具有不同用途，线和点不能作为面屏蔽区。锁定 ROI 可以防止现场调试时误拖动；停用 ROI 会改变执行输入，隐藏 ROI 则不会。
双画面适合比较模块输入与输出。开启联动后，两侧按归一化中心和可视比例同步，不代表两幅图拥有相同像素坐标。使用透视、仿射、裁剪、旋转或缩放工具后，应依据模块输出的偏移、比例或变换矩阵解释测量结果。

## 12. 运行界面与生产使用

`运行界面` 面向操作员查看检测状态，它与开发界面共享当前正式方案和真实执行器；进入页面不会自动运行，也不等于工程授权。启用保护后操作员仅运行健康封存会话内的完整根流程，可连续、暂停或停止；工程图片调试/范围批次收在单一“图片调试”菜单。运行卡显示当前项目、真实判定/耗时和报警，工程保护不替代设备/换型故障门禁。
现场使用前应完成三项检查：正式方案已经保存；所有外部输入和通讯目标可用；停止条件、超时和遇 NG 行为符合设备节拍。连续运行中不要修改方案文件或替换模型资源。需要调整参数时先停止运行、回到开发界面、保留原方案备份，再通过试运行验证并保存为新版本。
异常与 NG 必须区分。NG 是工具正常执行后得到的不合格判定；异常表示输入、参数、资源、HALCON 调用或通讯失败。生产统计可以包含 NG，但不能把异常当作正常良率样本。步骤 `记录` 中应保留执行时间、输入摘要、结果码和异常原因，便于追溯。

## 13. 配方保存、恢复与交接

示例程序、临时调整和新建流程在首次正式使用前必须执行 `另存为`。文件名应能识别产品、工位和版本，不建议覆盖仍在生产的旧方案。状态栏的未保存标记消失后，才表示流程顺序、连接、参数和 ROI 已写入磁盘。
打开方案时，平台会校验版本字段、工具种类、输入绑定和资源引用。旧方案可以在兼容范围内迁移，但迁移成功不代表所有外部文件仍存在。Shape 模型、脚本 DLL、本地图像和其他资源应与方案一起交接，并在目标电脑上重新执行自检。
软件维护单份恢复副本和备份用于应对意外退出或写入中断。恢复副本是故障保护，不是版本管理。重要投产版本仍应进入项目的正式文件管理或 Git 仓库，并记录 HALCON 版本、相机配置、标定数据和验证样本。

## 14. 故障排查顺序

遇到问题时建议按固定顺序处理，避免同时修改多个变量：
1. 检查当前方案、运行模式和选中图像是否正确。
2. 从第一个异常模块向上游查看，确认所有必需端口已有本周期有效值。
3. 在模块 `结果` 页读取 ResultCode、耗时和异常；再打开步骤 `记录` 获取完整上下文。
4. 检查 ROI 是否越界、有效域是否被屏蔽区全部扣除、图像通道和尺寸是否满足工具要求。
5. 对模型、DLL、HDevelop 文件和本地图像确认路径存在，并确认部署电脑可读取。
6. 只试运行当前模块；成功后再运行到所选或执行全流程，确认下游没有使用旧快照。
7. 若问题只在 Release 或独立启动出现，记录软件版本、HALCON 版本、方案和复现图片后再交给开发人员。
不要通过反复点击运行来掩盖偶发异常。相同输入和参数应产生可解释的确定性结果；任何不稳定现象都应保存原图、方案、日志和发生时间。

## 15. 方案变量与数组缓存

S109 新路径部分实现（待集中验证）。从全局变量页新建变量，选择“数值数组”或“文本数组”。默认值和当前值只显示数量与短摘要，旁边的“编辑…”按需打开完整 JSON：数值如 `[10.2,9.8]`，文本如 `["P01","P02"]`，空数组为 `[]`。确认写入草稿后点击变量页“应用”生效；取消不改正式值。

数组最多 10000 项，文本内容合计最多 262144 字符，编辑 JSON 最多 2097152 字符；拒绝 null、混合类型、嵌套数组和非有限数值，不静默截断。运行中须先停止再手动修改变量。

双击“写入全局变量”，在常用页选变量，然后在输入页连接当前类型的值；这里不再并排展示所有类型。读取/写入模块的数组端口分别是 `NumberArrayValue` 或 `StringArrayValue`，可直接连接数组统计、整理、脚本、分支和子流程；结果“更多”中可按需查看数组明细。`Changed` 比较所有元素和顺序，而不是短摘要。

默认值只供显式“恢复当前为默认”使用。保存方案包含默认值和当前值，重新打开恢复保存时的当前值，不自动清空。变量由同一方案全部根流程与子流程共享，按实际执行顺序读写；数组读写使用独立副本，已经发布的读取输出是本次快照，不是实时引用。它不是持久队列或并行数据库。存在读写引用的变量不能直接删除或改类型。

学习入口：`示例程序 → 数据 · 方案数组缓存与读写（无需图像）`。示例包含两条数据链：尺寸数组写入/读取后统计，产品标签写入/读取后取第二项。装载不会自动运行、外发或覆盖原方案；请主动运行并另存。

## 16. 结构化报文与类型化字段

S110 路径部分实现（待集中验证）。工具箱“逻辑/计算”新增“结构化数据读取”和“结构化数据组装”。双击打开统一参数窗，常用页只显示字段摘要和“配置字段…”；完整名称、路径、类型表按需打开，确认后仍需应用模块草稿。最多 32 字段，字段名可以改，稳定端口 ID 保留；已引用字段须先解除输入/下游/子流程返回引用，才能删除或改类型。

读取路径如 `/product/sn`、`/measurements/0`，区分大小写；数组索引从 0 开始，不能写 `00`。键中 `/` 写作 `~1`、`~` 写作 `~0`；空路径读取整个根值。不支持 JSONPath、通配符或递归搜索。每个字段明确选择 Number/String/Boolean/Number[]/String[]；缺失、null、空字符串和空数组有不同含义，缺失/null 报错，后两者在类型匹配时保留。数字字符串不会自动变为 Number。

读取模块未连接 Json 时使用“本地报文”中的文本，连接后必须取得上游本次有效 String，不因失败而回退本地。组装模块必须为每个字段连接实际值，路径各层均创建对象；`/items/0` 在组装时表示对象键 `0`，不自动推断数组。完整数值/文本数组作为一个字段传入，字符串自动转义。重复路径和父子覆盖被拒绝。

结果默认只显示关键字段/数量。“更多”可查看全部字段、数组明细或可复制的完整 JSON。全部字段成功后才发布本次结果，不产生半份输出，也不自动发送数据。标准 Number 为平台双精度数值，不是任意精度数字格式。

容量上限：JSON 文本 1048576 字符、深度 32、值节点 65536；单数组 10000 项，单文本及文本数组总内容各 262144 字符，字段路径 1024 字符/16 层。重复对象键、不完整 Unicode、非有限数字及超限内容报错，不截断。输入语法参照 [JSON 标准](https://www.rfc-editor.org/rfc/rfc8259)，字段路径采用 [JSON Pointer](https://www.rfc-editor.org/rfc/rfc6901) 的分段/转义规则；上述限额与严格类型是本产品约束，不宣称实现 JSON Schema。

学习入口：`示例程序 → 数据 · 结构化报文与测量结果（无需图像）`。四个模块完成读取产品/尺寸/标签 → 数组统计 → 结果组装 → 下游读取。装载不会运行或外发，示例需另存为正式方案。所有新增路径仍待集中验证。

## 17. 有界循环子流程

S111 部分实现（待集中验证）。双击现有子流程调用模块，在常用页选择“单次调用 / 固定次数 / 数组逐项”。固定次数为 0–1000；逐项先在子流程接口定义 Number[] 或 String[] 输入，再从下拉框选该输入，并在输入页连接实际来源。常用页按模式只显示次数或数组选择，保持原流程画布和统一参数窗。

进入内部编辑后，“调用输入”代理除普通上下文输入外，还提供 `$LoopIndex`（从 0 起）和 `$LoopCount`，逐项模式再提供 `$LoopItem`（Number 或 String）。可把当前项连接到公式、脚本和其他正式工具；内部预览只显示首项及数量，真实执行按原数组顺序逐项调用。每项清理上项运行结果，不能读取旧值。

在子流程接口的返回页，Number 或 String 返回可勾选“同时收集每次返回为数组”。原返回端口表示最后一次，额外的 `$Items` 端口发布正式 Number[]/String[]，可继续连接统计、方案变量、脚本或结构化报文。已连接或作为上级返回的端口须先解除引用，才能移除或关闭收集。保存/复制/撤销沿用原子流程定义和方案路径。

零次或空数组不运行内部模块，完成数和计划数均为 0、`$LoopHasLast=False`，有勾选的收集返回是空数组，普通最后一次返回没有值。任何一项失败、停止或超时都不发布半组返回；日志和调试明细显示执行到第几项。遵守原有 StopOnNg、断点和单步，不能中断单个 HALCON 算子。每次调用最多 1000 项，嵌套最多 8 层，单次根调用累计最多 10000 步。已经发生的变量写入或通讯发送等副作用不会回滚，设计现场流程时须考虑幂等与重试。

学习入口：`示例程序 → 流程 · 子流程逐项补偿与固定编号（无需图像）`。示例包含尺寸数组逐项补偿及结果数组统计，再固定三次生成编号并统计。装载不会自动执行或外发。新增路径仍待集中验证。

## 18. 多图像源任务工作区与验收边界

S113 双来源任务对比与成组检测部分实现（待集中验证）。双画面时，左侧来源下拉框可选系统输入、当前模块输入/输出或任意本地图像源；右侧继续使用“画面来源”。左右各有独立身份、状态、像素值和坐标链，缺图不借用另一侧。展开 `更多图像工具 → 图像队列 → 双源配对`，选择两个不同且启用的源模块和 A/B 图片目录；配对键是去掉扩展名的文件名，不区分大小写。缺图、重复键或单目录超过 1000 张会阻止配对。可选一组“预览两图”（只执行两源），再运行当前组或全部组。源文件/SN 仅在该组运行时临时指定，不改方案参数或 InputBindings。含双图差分/动态阈值工具时，尺寸、通道或像素类型不一致会拒绝该组。批次追溯保存组键、A/B 路径、来源模块身份和逐工具结果；当前不保存伪装成单图的双源快照。示例程序 `图像 · 双源配对与绝对差分` 默认两源使用同一 HALCON 颗粒图片，仅供学习连线；实际检测应使用自己的配对目录。

S112 多图像源工作区部分实现（待集中验证）：同一流程可添加多个“本地图像源”，各自设置文件并通过类型化 Image 端口连接不同处理链。运行后在图像区“画面来源”选择指定图像源；下拉列表显示运行状态或尺寸。指定来源尚未运行、停用或出错时，画面保持空白并给出原因，不会静默显示最后加载的其他图像。当前模块输入/输出与双画面入口仍保留；切换画面不改流程位置和参数窗口。

新建 ROI 记录当前 ImagePixel 来源并随方案保存；新来源 ROI 与其他图像链的模块不能在 ROI 绑定页选择，结果 Region/XLD 叠加只出现在同一坐标来源画面。旧方案未记录来源的 ROI 为兼容保留原语义，复杂项目建议重新按来源建立 ROI。图层显隐不改变算法订阅或释放结果。选择 `示例程序 → 图像 · 双来源独立检测` 可学习两路来源分别驱动阈值/轮廓和灰度分布；示例依赖本机 HALCON 示例图像，缺失时请分别在两个源模块中选择图片。它不是相机硬件同步、自动换型或多画面并行调度。

当前版本已经具备较完整的本地图像流程、Region/XLD 处理、测量、Shape 定位、二维代码、类型化几何、脚本/DLL、TCP、配方、调试和运行页入口，但仍不是成熟工业平台的终点。相机厂商 SDK、完整标定与坐标体系、子流程和多流程调度、真正多画面、资源中心、权限审计、部署工具、设备级协议和长期稳定性验证仍需后续迭代。
因此，验收某项能力时必须沿着 `工具入口 -> 参数配置 -> 输入 -> 执行 -> 输出/图形 -> 记录/异常 -> 配方保存 -> 独立验证` 逐项检查。只有内部类、数据结构或没有用户入口的代码不能算产品功能；只有按钮、页面或说明而没有真实算法执行也不能算完成。

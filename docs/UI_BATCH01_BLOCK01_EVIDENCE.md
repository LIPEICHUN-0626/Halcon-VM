## 实际问题与修改

- 修复积压编译错误后，隔离启动基线发现右下RightTabs.SelectedIndex=-1、SelectedContent为空；不是根据旧总结推定空参数页。现在显式选择原ModuleResultTab，并补标准内容宿主，实际返回0/非空。
- 工程页不平铺OK/NG/良率/节拍，操作员运行页仍保留原统计。默认显示原流程状态和选中模块摘要，低频流程/逐ROI结果展开后保留原控件与命令；有实际错误才展示错误行。
- “模块参数 / 输入订阅 / 运行结果”含义明确并有悬停解释。结果按钮只选原结果页，不打开参数小窗，不运行算法，不改选择和布局。没有可编辑模块时参数/输入按钮禁用，直接调用任务也拒绝空编辑。
- 参数仍复用原双击小窗/草稿/F5/应用，不挤主工作区。原确认取消或开窗失败后，任务不向旧模块编辑器继续路由，不显示成功文案。这一确认分支未自动打开确认窗实测。
- 流程卡记录/端口按钮显式19px最小高度，消除全局28px最小高度挤压；8px连接点和真实绑定/执行顺序不改。

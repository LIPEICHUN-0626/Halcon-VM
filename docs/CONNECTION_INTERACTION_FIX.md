# 连线操作与即时绑定修复

日期：2026-08-31。状态：已验证实现。Git 小交付：6/10，不提交/推送。

## 本轮 A/B 与范围

- A 线：修正底部圆点位置；扩大容错命中并处理缩放及相邻节点；连接可落在整个模块上；两次点击模式显示待连接反馈。保持纵向小卡、小圆点与简单折线。
- B 线：自动匹配并写入真实输入；连接检查区改为按需“输入绑定”来源下拉，改选立即应用，支持运行结果失效、日志、配方及撤销/重做。低频操作默认折叠，“全部输入”进入中央四任务工作台。
- 仅改连接交互与输入编辑，不改 HALCON 算法、相机 SDK、执行顺序或配方格式。工作区已有 S81 OCR/图像布局开发改动保留，不计作本轮完成。

## 原因与修复证据

1. 原 XAML 上下锚点都位于标题行；实际窗口测得模块高 68，而底部输出点中心 Y=49。新增回归在修改前明确失败，修复为跨完整三行定位。
2. 原连接目标只识别精确端口/锚点；点击模块主体进入选择/拖动，不能自动绑定。现在连接期间由画布优先处理，精确端口仍优先，普通目标卡自动解析兼容输入。
3. 缩小后旧命中矩形随流程缩小。增加以屏幕 DIP 计算的邻近命中，横向容差 24 DIP、纵向最多 14 DIP（紧凑卡限制为高度的三分之一）；范围重叠选择最近端点。已有连线选择不被邻近起点抢走。
4. 原绑定改选需另进输入页并应用。现在选中/完成连线后显示紧凑绑定栏；选择来源立即走现有校验和真实 InputBindings，参数草稿有保护，运行时拒绝修改。

## 用户路径

1. 拖来源模块底部圆点到目标模块，松开；或者先点来源底部圆点，再点目标模块。
2. 系统立即选择兼容的前序输出并绑定，状态显示实际来源与目标。
3. 不合适时在“输入绑定”下拉中直接重新选择。以后点击连接线也可重新打开此栏。
4. 多输入的完整配置在“详情与操作 → 全部输入”；无效目标不会修改旧连接，Esc 可取消正在建立的连接。

## 仍有边界

- 确定性前向执行、类型和双输入重复来源校验保留；不允许把无效连接伪装成连通。
- 精确端口操作遇到多个兼容输入时仍要求明确选择；模块级连线自动选择后可改选，不保证自动猜中业务含义。
- 未验证真实产线长期操作、外部设备或缺少样本的 `.jw/.handle` 工程。S81 OCR 及图像显示改动仍需独立完整验收。

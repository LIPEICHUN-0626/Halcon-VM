## 实际问题与交付

- 原聚合连接将多个兼容组合按分数和名称排序后直接取首项，会静默选择数值来源或同类型目标输入。现在只有唯一兼容组合直接连接；多个组合复用原小栏，短中文“来源含义→目标输入含义”，悬停看模块/正式端口/类型，明确点选后才绑定。原评分只排序展示，不替用户决定。
- 同类型的ImageA/ImageB及Width/Height等输入输出不猜；原方向、前序顺序、启用态、正式类型与双输入重复端点规则仍生效。候选基于真实端口定义，允许未运行时搭建工程，不把候选存在当作已有运行值、坐标/模型最终资格或生产就绪。
- 原绑定栏直接显示正式端口中文名、端口名与兼容来源数量；无效旧来源保留但不可选。选择后沿原绑定路径生效、清目标/下游旧结果，可撤销和保存；来源/目标弱实例重核，不能用同ID新实例承接旧选择。
- 候选与连接会话、编辑租约关联；忙碌、停用源、过期租约、删除/替换对象拒绝。原草稿确认后进一步检查原源/目标实例仍在当前流程，再走原配置/坐标检查及回滚。不自动执行、应用其他草稿、连接设备或外发。
- 离屏渲染暴露候选栏与旧绑定栏重叠/视口边缘裁切，已在选择期间只显示原候选栏，并按当前滚动/缩放可视范围约束其位置。关闭/Esc取消待选并保留订阅，结束后恢复原检查栏。小栏只临时覆盖画布，不缩小主流程布局。
- 原画布PreviewMouseUp会在待连接状态吞掉Button的Click，已对候选/关闭按钮避让；选择期间不继续绘制鼠标跟随预览。实体鼠标未接管，测试仅验证原处理器及真实界面Button.Click路径。

# S123 设备握手与检测结果回传

状态：A/B 代码已接入，部分实现（待集中验证）；未做本轮编译、交互或真实 PLC 验收。S122 同样待集中验证。

A 线：在既有通讯工作区与运行页按需呈现一次检测任务的“触发来源 → 目标流程 → 判定值 → 回传目标”短路径，显示待机/运行/忙碌丢弃/已回传/失败状态，相关配置返回原模块或方案配置；不把多个低频命令堆到顶部。明确区分调试、离线模拟和真实设备启用。

B 线：在当前确定性单执行槽上，让受信任设备的明确触发进入固定流程，并把本次已完成的 OK/NG/异常映射为显式配置的 Modbus TCP/RTU 05/06 单点写入或现有 TCP 文本结果；带结果归属、超时、忙碌、不重放写入、停止、切换方案和离线模拟保护。若缺少安全可定义的目标、设备协议或回传映射，不自动猜测 PLC 地址。联机/断线/重复触发与现场 PLC 验收之前不得称为生产闭环。

本轮接入：通讯页原 TCP 触发折叠区内增加按需回传目标、映射、PDU 地址/设备与状态，不新增顶部按钮；启用状态不随方案恢复。原固定流程和唯一执行槽保持到回传结束；本次运行生成独立 RunId，显式回传模式抑制旧自动结果发送，绝不读取上次外发缓存。结果仅在同一触发会话、流程/方案未切换、原连接仍在且非模拟时回传。Modbus 05/06 借用现有单次调用与回显校验，RTU 独占串口，失败或交付状态不确定均停止触发且不自动重放。TCP 文本为 `RESULT=...,VALUE=...,FLOW=...,RUN=...` 的 ASCII 换行帧，发送有界超时。

05 线圈只有两态，只允许 OK/NG 映射 0/1，执行异常不写；06 寄存器支持明确不同的 OK/NG/异常三态。用户停止、流程超时、离线模拟、目标变化均不写 PLC。不是跨设备事务、PLC 确认业务语义、消息去重或生产追溯。现场点表、网络/串口隔离、断线与超时不确定性仍需在集中验收阶段验证。

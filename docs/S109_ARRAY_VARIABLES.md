## B 线

正式数组通过稳定 VariableId 显式读写方案共享变量；根流程/子流程沿用同一变量集合，跨作用域引用保护复用现有路径。读写值独立复制，Changed 比较完整元素与顺序；数值数组逐项精确比较，旧标量容差规则保留。写入读取真实上游有效输出，不回退到默认或旧值。

默认与当前数组以独立 JSON 字段随变量保存，旧标量字段不变；保存包含两者，重新打开恢复保存时当前值，显式重置才回到默认值。读取文件提前校验数组，恢复变量集合在清空前先准备全部数据。手动应用/重置使当前活动作用域的相关输出和下游失效；其他根流程切换沿用既有结果隔离。运行写入不反向清除已执行读模块的快照，后续读模块取最新当前值。

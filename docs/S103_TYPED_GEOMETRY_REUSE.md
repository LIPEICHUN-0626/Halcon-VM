# S103 类型化几何与点集复用

状态：本主题既定开发路径已写入，部分实现（待集中验证）。2026-09-10 更新；未编译、启动或验收，不计已验证 Git 次数，不代表体验已达标。

## 用户价值

当前已有 Point2D、Point2D[]、Pose2D 以及直线/圆/椭圆等正式几何输出，但 S101 分支和 S102 子流程边界仅支持标量及 Image/Region/XLD。这使测量、定位、点集拟合在封装或条件汇合时无法完整复用；不能用字符串代替类型化数据，更不能丢失坐标身份。

## A 线：按任务选择类型和查看结果

复用统一参数窗、分支类型选择和子流程输入/返回入口，按“数值文本 / 图像图形 / 几何点集”组织既有类型，减少长技术类型列表。来源只列兼容端口，点集默认显示数量、有效性与坐标来源，明细按需打开；不新增永久顶部按钮，不新建一套参数状态。提供可主动选择的“几何/点集经过子流程返回后继续拟合或计算”示例与中文帮助。

## B 线：真实跨调用、分支与下游契约

先读取当前几何模型、执行器和端口元数据，确认实际已支持类型及其克隆/坐标/异常契约。将同一套类型规则用于子流程封装、输入代理、返回值、复制/配方、连续草稿，以及分支选中值发布。复用现有几何模型，不做另一套同名 DTO；不得把可变点集合的引用直接泄漏到内部实例或下游。

输出继续驱动已有点集分析/拟合或几何计算，错误、空集合、部分无效点、坐标不一致和被跳过分支明确处理。运行时坐标身份不因嵌套调用改成随机 ID，也不自动做不存在的标定转换。已有 HALCON 工具不机械重写。

## 已写入的 A/B 路径

A 线：原分支结果类型和子流程添加输入/返回的类型选择统一按“数值文本 / 图像图形 / 几何点集”分组，不加永久工具栏。Point2D[] 默认摘要为点数、有效/异常项与坐标身份，不展开长坐标串。返回来源和调用端口记录补几何坐标提示。

B 线：六类既有模型 Point2D、Point2D[]、Pose2D、Line2D、Circle2D、Ellipse2D 接入分支实际选中值发布、子流程边界校验及代理/返回深复制。共享类型规则同时进入元数据和参数验证；不新增第二套几何 DTO。单值复用原模型有效性校验；点集要求有效容器与统一 ImagePixel 坐标，保留空集合和 null/无效点，由下游原有最小点数与异常点策略处理，混合坐标明确拒绝。所有几何克隆保留坐标身份，点列表及成员独立复制。

圆周卡尺点集的图像身份改为解析真实 Image 输出端口，避免内部输入代理/随机运行实例 ID 改变坐标链。坐标解析识别几何对象自身身份并补 Pose2D；内部仅有几何输入时，调用图像记录可以按唯一坐标身份寻找仍有效的真实参考图，找不到或存在混合坐标则不猜测底图。

顶部示例新增自制圆形图像：第一个子流程用 240° 圆弧卡尺和点集统计返回 Point2D[]/Point2D；第二个子流程把点集作为输入进行统计/拟合并返回 Circle2D/Radius；下游点圆关系及半径判定继续消费真实结果。圆弧质心不是拟合圆心。装载复用已有草稿/未保存确认、显式运行与保存流程，不需要外部设备或厂商示例资产。该示例尚未运行验证。

## 本次续接的 A/B 路径

A 线：结果页原有“更多 · 全部输出与明细”内，仅有值的 Point2D[] 输出显示“点集明细”。打开点击时的独立只读快照，每页 200 项，保留原始索引、完整精度行/列和异常原因，可只看异常点。分页不删减原始数据，重跑不悄悄更换正在查看的快照；表格分页不代表整个快照内存有固定上限。空集合、空成员和无效容器分别说明，不新增永久顶部按钮。

B 线：主图像当前模块输入/输出与双图像输入接入同一几何坐标来源解析。只有唯一、有效且已确定的坐标身份才能关联仍存活的真实 Image 输出；几何分支输入只使用实际选中的路径。未运行、错误、混合坐标或底图失效显示空状态和原因，不回退到可能无关的全局图。关联图明确标为参考底图，不把几何输出冒充 Image 输出，显式 Image 输入和历史图语义不变。

新增七模块“数据 · 判定选择几何分支（自带图像）”示例：原拟合半径驱动数值判定，未通过时才调用另一种 Geometric 圆拟合；分支在原 Circle2D 与备选 Circle2D 中选择，继续点圆测量。默认半径范围为 60–70，可主动缩窄判定范围探索假分支；不自动运行，不把备选算法宣称为更优，也不把原 NG 判定改为通过。两个几何示例均未运行验证。

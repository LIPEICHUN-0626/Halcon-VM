## 用户可见变化

- 双击支持 ROI 的模块后，中央 `ROI` 页默认只显示“来源策略、前序区域、本地检测/屏蔽数量与当前状态”；本地 ROI 长清单、位置修正和逐区执行统一收进默认折叠的“更多”。
- 来源策略提供 `本地绘制 / 继承前序 / 合并本地与前序` 三个直接选择。连接画布、卡片主体自动绑定或输入页选择 Region 后会同步切到继承；用户仍可在绑定栏重新选择。
- 左侧工具箱固定为 `全部 / 常用 / 收藏 / 最近 / 片段` 五个直达模式，76 个工具按 10 类就地展开；已删除失效的“大类弹出菜单”和内部 `Category` 模式，避免以后回退成二级选择。
- 流程卡保持普通单击选中并可直接拖动画布位置，双击才打开中央配置；上下圆点仍为 8 px，命中区 `18×16 px`，连接线命中带 8 px。

## 真实执行语义

- `本地绘制`：位置修正后的本地检测 ROI，扣除已启用本地屏蔽区。
- `继承前序`：使用前序工具本周期有效的托管 Region，扣除本地屏蔽区；本地检测 ROI 不参与。
- `合并本地与前序`：先对前序多对象 Region 执行 `union1`，再与本地检测 ROI 执行 `union2`，最后扣除本地屏蔽区。
- 继承来源必须是启用、位于当前模块之前、当前周期执行成功且托管快照仍有效的 Region；上游失效、空域、类型、顺序和运行中修改均给出明确异常并失效下游。
- Image 与 Region 必须来自同一 `ImagePixel` 图像链。仿射、缩放、裁剪或其他新坐标图像上的 Region 不能绑定到原图工具；本轮不冒充跨相机、世界坐标或标定转换。
- 来源策略与真实 `InputBindings` 进入配方、复制和撤销/重做；旧配方继续按历史相交语义读取，用户明确应用后才迁移到新策略。
- Shape 搜索、HDevelop 兼容路径和通用 ROI 工具统一复用有效区域生成，不再各自绕过继承规则。

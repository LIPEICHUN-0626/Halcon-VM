# S99 模块实例批量编辑

状态：部分实现（待集中验证）。按用户要求，本轮不执行编译、回归或验收。

## A 线：多选后按需编辑

编辑菜单提供“批量编辑所选模块”，不增加永久工具栏按钮。批量命名先预览旧名→新名，支持前缀、起始编号及保留原名；按真实执行顺序编号，限制 64 字、控制字符和不区分大小写的名称冲突。取消不修改流程。

## B 线：真实判定规则复用

多选至少两个数值判定模块，指定其中一个作为规则来源，展示比较方式、上下限和容差及接收模块。确认后只修改这四项；输入绑定、ROI、名称、启用状态、位置、顺序与输出快照不被复制。混选其他工具时明确拒绝，不把全量参数 DTO 强行覆盖到别的工具。

两项均复用当前多选实例、草稿确认、配方脏状态、结果与下游失效及一次撤销记录。运行、批次和历史查看期间禁止开始批量编辑；提交时仍确认目标实例存在。修改后重新载入受影响的正在编辑模块参数，不创建第二份长期草稿。

实际可用性、取消分支、撤销/重做与保存后重载均留待集中验证。后续通用字段级批量编辑与可复用参数预设尚未实现，不宣称支持全部工具批量参数。

# S129 颜色选样与 HSV 检测

状态：2026-10-02 代码已接入，部分实现（待集中验证）。S111–S129 增量仍待集中验证；没有编译、启动、回归或鼠标验收结论。

A 线：原检测分类新增“HSV 颜色检测”，双击复用参数小窗。常用只有色相、容差、饱和度下限、亮度下限四项；S/V 上限进入单一更多参数。点击图像取色后在模块 RGB 输入画面单击，实际 HSV 色相填入同一草稿，并显示颜色小块/坐标/H/S/V 短摘要；支持取消/Esc。取样不应用、不运行、不保存样本色块，不缩流程区。输入/ROI 来源未应用时拒绝取样，图像更换、运行或关闭参数窗结束取色；双画面也只允许该模块的订阅输入画面。

B 线：显式必需 RGB Image、可选 ROI；HALCON reduce_domain/convert_image_type/scale_image/decompose3/trans_from_rgb(hsv)/threshold/intersection/connection 进入原执行器。byte/uint2 分别按 255/65535 固定归一化，real 有效域必须为 0–1，其他类型和非三通道拒绝。HALCON real HSV 的弧度色相转换为界面角度，S/V 为百分比；±范围跨 0° 使用双段并集，容差 180° 不限色相。输出托管 Region、Area、AreaRatio（%）、RegionCount、SampleCount（有效像素分母）、HasMatch、HueCenter/HueTolerance、Parameters/ResultCode，遵循原输入图像坐标链和资源释放。参数纳入原配方/复制/草稿/撤销路径，结果画像优先显示比例、面积、数量和色相。

比例分母严格为图像 domain∩有效 ROI（检测区、位置修正、屏蔽和前序区域复用原规则），空域报错。零匹配是有效执行 OK、空 Region、0% 和 HasMatch=false；产品 OK/NG 由下游数值判定决定，不把算法执行成功冒充合格。低饱和（<3%）或暗（V<2%）的取样点拒绝自动填色相，黑白灰可手填容差 180° 并限定 S/V。不是光源标准化、颜色学习或多色分类。

学习入口：示例程序→检测·颜色取样与覆盖比例，显式装载“RGB 图像源→HSV 检测→区域面积筛选”，AreaRatio 同时接数值判定；默认红色范围和 0.1–100% 仅用于学习。尝试读取本机 HALCON `color/color_fuses_00.png`，缺图提示自行选择，不自动运行、不影响空白启动。中文版帮助手册含该工具完整步骤。

实现文件：`MainWindow.S129.cs`、`Models/VmColorInspectionS129.cs`，及原 XAML/执行器/工具元数据/参数合同/常用与结果画像/示例/帮助/项目包含。直接核对本机 HALCON 20.11 API 和 [MVTec trans_from_rgb 文档](https://www.mvtec.com/doc/halcon/2011/en/trans_from_rgb.html)，未运行算法测试。

## 实际改变

- 滤波Mean只读宽高，Median只读半径；增强Linear只读增益/偏移，Local只读窗口/因子；通道只在Extract读取序号，绝对差分不读偏移，透视只在ExplicitSize读尺寸，数值运算只在Round读小数位数。当前不适用字段的文本不写入参数，保留已应用Clone；不是按控件IsVisible决定是否读取，因此“更多”折叠不绕过适用参数校验。
- 六类模式显示/解析统一读取实际SelectedItem，避免SelectionChanged先于SelectedValue提交而错显旧模式。透视只读几何预览与应用共用尺寸检查，Round的模型校验也按模式限定；旧配方Normalize未修改。
- 局部增强4项、透视显式尺寸4项、Round精度直接在常用页，短数值96–140DIP，透视同排下拉112–140DIP。滤波/增强窗口与半径标注px，技术解释转悬停。透视四点原第4行曾不受“更多”控制，现16坐标及低频恢复/复制操作完整随原高级区收起，主图上编辑入口保留；无新图像编辑器。
- 当前字段非法时就近红框和一条范围说明，常用错误不展开无关高级项；编辑/取消/换模块清除标记。0、偶数、NaN和超限在当前字段明确拒绝，不先Normalize偷偷换默认值。非激活窗口不主动Focus。

# S115 采集诊断与触发任务

状态：代码已接入，部分实现（待集中验证）。真实相机硬件未连接验收；不宣称多相机同步、外部硬件触发或生产稳定性。

2026-09-28 接线范围：原图像源参数窗按来源模式显示自由采集/软件触发或折叠的离线故障模拟，并在单一“采集诊断”折叠区显示上次来源、UTC 帧时间、耗时、帧号和错误。图像工作区只在选中具体图像源时露出一行采集状态；连接/运行异常或配置缺失时有“打开源配置”入口，不添加默认顶部按钮。Image 输出继续走原订阅链；新增类型化 AcquisitionMs、TriggerMode 输出，连同原来源/时间/帧号。连接态、上次诊断和回放游标均不写配方。

软件触发：连接时向真实 HALCON 接口查询 `TriggerSource_values` 和 `available_param_names`，明确拒绝缺少 Software / TriggerSoftware 的设备；记录原触发设置，配置 Software、启动采集。每次原图像源模块执行发出一次 `TriggerSoftware` 命令，再 `GrabImageAsync` 取一帧；失败释放句柄、不回退旧图。断开尽力恢复原设备触发设置并关闭。依据本机 HALCON 20.11 官方 GigEVision2 软件触发示例接线，其他接口只有通过实际能力探测才能连接，硬件行为待集中验证。

离线模拟：参数可设每 N 次请求缺图（0 关闭、N=2–1000）和最小请求间隔（0 关闭、上限 60000 ms）。失败不读图、不推进文件游标、不复用旧输出；请求次数与节拍时钟属于本次会话运行态。切换配置/方案会重置。它不是设备实际丢帧统计或硬件触发仿真。

A 线：在原图像源参数与图像区按需显示采集来源、连接态、上次采集时间/耗时、帧序号和最近错误；明确“当前模块采一帧”与“运行整条流程”的区别。低频诊断折叠，不增默认顶部大按钮；发生采集故障可直接定位到源模块的连接/参数。

B 线：已写入 HALCON 能力检查、自由采集/软件触发的单帧路径及离线节拍/缺图模拟，复用同一 Image 输出和原执行器、配方、停止与日志。单个 HALCON 抓图算子不能由 UI 中途取消；超时取决于实际接口是否支持 `grab_timeout`。禁止冒充硬件同步、自动重连、异步连续采集或生产稳定性；硬件相关结论留到集中验证。

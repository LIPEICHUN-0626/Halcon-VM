## 可直接使用的目标

继续把 `D:\codex\codex1` 改造成尽量完整复刻海康机器人 VM / VisionMaster 页面、功能、显示区域和用户习惯的工业视觉开发平台；全部视觉算子、图像处理、定位、测量、标定和坐标转换统一由 HALCON/HDevEngine 实现。

开始前完整阅读 `AGENTS.md`、`docs/VM_OFFICIAL_REFERENCE_SPEC.md`、`docs/CODEX_MASTER_PROMPT_VM_REPLICA.md`、`docs/PRODUCT_GOAL.md`、`docs/PRODUCT_ROADMAP.md`、`docs/SPRINT_BACKLOG.md`、`docs/PRODUCT_GAP_ANALYSIS.md` 和 `docs/BSB_REQUIREMENTS.md`，并以活动代码和可复现验证为准。

永久规则：

1. VM 始终只指海康机器人 VM / VisionMaster；不做 Cognex、通用 Graph 或只换皮的软件。
2. 每轮自行执行 A/B 双线：A 线必须有肉眼可见的 VM UI/UX 升级；B 线必须有可从 UI 配置、运行、保存和验证的真实通用工业能力。
3. 默认首屏必须安静。新增功能原则上不得新增永久工具栏按钮；低频能力进入菜单、`更多`、上下文菜单或当前对象任务面。
4. 不得以内部分层、假按钮、空页面、编译通过或模拟数据冒充产品完成；必须形成入口、参数、输入、执行、输出/图形、日志/异常、配方和验证闭环。
5. BSB 是长期验收场景，但当前按用户指令暂停；收到明确恢复指令前不开发、不验证、不宣称完成。
6. 每轮执行 Debug/Release x64 编译、独立启动、HALCON/旧配方/异常路径和实体 UI 验证，并更新全部产品文档。
7. 每个验证交付记入 `docs/GIT_BATCH_LOG.md`；累计 10 次统一提交并推送 GitHub，之后从新的批次锚点重新计数。
8. 长期目标不因单个 Sprint 完成而结束。

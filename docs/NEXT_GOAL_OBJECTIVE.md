# 下一长期目标执行文件

更新日期：2026-08-24

## 唯一长期目标

把本项目持续建设为“海康机器人视觉平台 VM / VisionMaster 类型的完整工业视觉平台体验 + HALCON 算法内核”。页面分区、工程流程、工具组织、参数编辑、输入输出订阅、图像/ROI、调试、资源和生产运行习惯向 VM 对齐；视觉算子、定位、测量、标定与坐标计算使用 HALCON。允许形成项目自己的克制型工业设计风格，不复制海康商标、图标、截图、手册资产或专有源代码。

BSB 是长期核心验收场景，但当前继续冻结。收到用户新的 BSB 实施指令前，不开发、宣称或验证 BSB 专项工具、协议、坐标和产线逻辑。

## 永久执行规则

1. 每轮自动 A/B 双线执行，不再逐轮等待确认。
2. A 线必须产生肉眼可见、符合 VM 使用习惯的 UI/UX 或工作流升级，并用实体截图回答默认首屏减少了什么、注意力落在哪里。
3. B 线必须新增一个从 UI 可配置、可运行、可独立验证、对通用工业视觉有真实价值的功能；不得只有 Model/Service/Adapter 或假入口。
4. 每轮必须形成“目录入口 -> 参数 -> 输入 -> 执行 -> 输出/图形 -> 日志/异常 -> 配方 -> 验证”闭环。
5. 默认界面只保留高频动作；低频能力进入菜单、更多、上下文或选中对象任务面。新增功能原则上不得新增永久顶部按钮。
6. 代码完成度以实际源码和可复现验证为准，文档与代码冲突时立即纠正文档。
7. 所有视觉算子和几何结果必须有真实 HALCON 或经验证的明确数学实现，不得用字符串解析、假数据或静态演示冒充类型化运行链。
8. 受信任 C#/DLL 自定义模块继续作为正式流程能力维护；HDevelop 兼容入口不等于脚本/SDK 已完整。
9. 每 10 次已验证小交付统一检查、提交并推送 GitHub。S56-S65 已达到 `10/10` 并在本轮统一提交推送；S66 从新批次 `1/10` 开始。

## 当前下一轮：S66

### A 线：VM 式长流程插入导航

目标不是增加更多常驻按钮，而是让复杂流程里的工具真正“找得到、看得懂、插得准”。

- 保持 60 工具/9 类完整目录、搜索/收藏/最近和按需能力预览。
- 工具箱选择与当前流程节点联动，明确当前插入锚点。
- 从工具行、节点上下文菜单和键盘入口提供“插入到所选前/后”，并落到真实确定性 `flowTools` 顺序。
- 能力预览显示当前锚点附近的兼容上游输出、下游输入、可自动订阅项和拒绝原因。
- 插入成功后高亮真实位置、连接和受影响节点；失败时就地解释类型、顺序、启用或来源问题。
- 不增加永久顶部按钮，不把确定性线性执行冒充自由并行 Graph。

### B 线：类型化 Line2D 与点到直线距离（非 BSB）

- 定义可克隆、可显示、可 JSON 往返并带 ImagePixel 上下文的 `Line2D` 数据契约。
- 现有 XLD 直线拟合在保留端点、角度、残差等旧输出的同时发布类型化主线。
- 新增“点到直线距离”流程工具，显式订阅 `Point2D + Line2D`，输出垂足 Point2D、无符号距离、有符号侧向值、托管 XLD、参数和 ResultCode。
- 进入工具目录、右侧常驻参数、真实连接、I/O、端口数据监视、日志、配方、复制重映射、撤销/重做和 NumericJudge 下游。
- 拒绝错误类型、退化直线、非有限值、不同 ImagePixel 上下文、未运行/陈旧来源，并正确释放旧托管输出。
- 首版仅承诺同一图像像素坐标，不含标定、世界单位、跨相机、机器人/振镜或 BSB。

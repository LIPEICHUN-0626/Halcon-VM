# 下一长期目标执行文件

更新日期：2026-08-27

## 唯一长期目标

把本项目持续建设为“海康机器人视觉平台 VM / VisionMaster 类型的完整工业视觉平台体验 + HALCON 算法内核”。页面分区、工程流程、工具组织、参数编辑、输入输出订阅、图像/ROI、调试、资源和生产运行习惯向 VM 对齐；视觉算子、定位、测量、标定与坐标计算使用 HALCON。产品必须形成自己的克制型工业视觉风格，不复制海康商标、图标、截图、手册资产或专有源代码，活动界面不得把 `VM/VisionMaster` 当作本软件品牌露出。

BSB 是长期核心验收场景，但当前继续冻结。收到用户新的 BSB 实施指令前，不开发、宣称或验证 BSB 专项工具、协议、坐标和产线逻辑。

## 永久执行规则

1. 每轮自动 A/B 双线执行，不再逐轮等待确认。
2. A 线必须产生肉眼可见、符合工业视觉工程习惯的 UI/UX 或工作流升级，并用实体截图回答默认首屏减少了什么、注意力落在哪里。
3. B 线必须新增一个从 UI 可配置、可运行、可独立验证、对通用工业视觉有真实价值的功能；不得只有 Model/Service/Adapter 或假入口。
4. 每轮必须形成“目录入口 -> 参数 -> 输入 -> 执行 -> 输出/图形 -> 日志/异常 -> 配方 -> 验证”闭环。
5. 默认界面只保留高频动作；低频能力进入菜单、更多、上下文或选中对象任务面。新增功能原则上不得新增永久顶部按钮。
6. 左侧模块箱只保留一个可见 `分类` 入口；完整工具与流程片段由该入口按需切换，不恢复模式按钮墙。
7. 默认流程从上到下排列并调试，模块保持紧凑，连接必须简洁并对应真实 `InputBindings`；步骤日志和通讯交互通过节点 `记录` 子页面查看。
8. 代码完成度以实际源码和可复现验证为准，文档与代码冲突时立即纠正文档。
9. 所有视觉算子和几何结果必须有真实 HALCON 或经验证的明确数学实现，不得用字符串解析、假数据或静态演示冒充类型化运行链。
10. 受信任 C#/DLL 自定义模块继续作为正式流程能力维护；HDevelop 兼容入口不等于脚本/SDK 已完整。
11. 每 10 次已验证小交付统一检查、提交并推送 GitHub。S66-S75 已达到 `10/10` 并完成统一门禁；下一批从 S76 重新计数。

## 当前下一轮：S76

### A 线：长流程“任务透镜”与非相关步骤低噪折叠

目标是在不隐藏执行语义的前提下，进一步减少默认长流程页面的卡片噪声，让注意力落在当前步骤、直接依赖、图像和参数。

- 在默认任务聚焦下，所选步骤、直接上游/下游、执行指针、断点、异常和阻断步骤保持完整 `280 x 68 px` 卡片；其余非相关步骤收为可点击的紧凑状态行，不永久展开名称、端口和命令。
- 紧凑行仍必须显示确定性序号、最短可识别名称、OK/NG/等待/停用状态和上下小锚点；点击、键盘上下定位或导航命中后立即展开为当前任务，不能形成不可交互的缩略图。
- 提供按需“全部展开/任务透镜”切换，放入流程 `更多`，不得新增永久顶部按钮。切换只影响显示，不改工具顺序、`InputBindings`、执行计划、运行结果、断点、Group、配方或撤销栈。
- 分支/汇聚、手动布局、组合折叠和连接 Inspector 必须保持真实。紧凑行连接继续使用简洁直线/直角段，聚合锚点仍可真实选择精确端口、拖接、替换和清除。
- 用 1938×1158 与 1366×768 实体截图对比默认首屏可见完整卡片数、紧凑行数、横向滚动和永久按钮数；用物理鼠标/键盘验证展开、切换、锚点和执行跟随。

### B 线：类型化 Line2D + Ellipse2D 交点/弦长测量（非 BSB）

- 新增“直线段与椭圆交点/弦长”，显式订阅同一稳定 `ImagePixel` 上下文的 `Line2D` 与 `Ellipse2D`，可直接消费现有直线拟合/两点构线和 S74 椭圆拟合输出。
- 实施前确认本机 HALCON 20.11 `gen_contour_polygon_xld`、`gen_ellipse_contour_xld`、`intersection_contours_xld` 的 .NET 签名与重叠语义；按 `Line2D` 有限线段计算，不把无限直线结果冒充线段结果。
- 输出类型化 `IntersectionPoints:Point2D[]`、`Point1/Point2`、`IntersectionCount`、`ChordLength`、`Relation`（Disjoint/Tangent/Secant/Overlapping）、上下文、参数、ResultCode 和托管直线/椭圆/交点 XLD。
- 右侧常驻关键参数至少包含交点容差、椭圆采样精度和显示十字尺寸；主要参数不得依赖弹窗。`IntersectionCount/ChordLength` 必须真实驱动 NumericJudge。
- 覆盖 0/1/2 交点、切线、弦、线段端点命中、交点顺序、旋转椭圆、近圆、短线段、退化/非有限几何、混合上下文、同源/顺序、未运行/陈旧、旧 XLD 清理、配方、复制、监视和日志。
- 首版只承诺同一图像像素坐标，不含标定、世界单位、跨相机、机器人/振镜或 BSB。

# S107 脚本 / DLL 类型化数组接口

状态：2026-09-15 首版完整接口路径已写入，部分实现（待集中验证）。保留 `ScriptScalarValue` 的既有类型名、标量字段/方法和固定入口，扩展正式 Number[] / String[]，不是更换脚本引擎或另建界面。

## 当前实现

- 现有接口设计器可选择数值/文本数组，默认值按 JSON 编辑并就地显示类型、数量、短摘要或错误；类型为标量时不占用数组说明空间。已有代码访问片段生成对应数组 SDK 调用。
- 原代码折叠区新增“按接口生成代码”，根据已应用命名输入/参数/输出生成读写模板；替换非空草稿前确认，不修改正式代码、不执行。模板默认同类型透传或显式空值，只作为学习起点，不冒充检测算法。
- 命名输入与参数支持 `GetInputNumberArray/GetInputStringArray`、`GetParameterNumberArray/GetParameterStringArray`，输出支持 `SetNumberArray/SetStringArray`。脚本取得原生 double[] / string[] 独立副本，发布时再次复制，流程端恢复 S105 正式数组。
- 跨 AppDomain 只序列化私有原生数组，新字段标记 OptionalField；反序列化、域内返回前、域外接收和命名发布前校验。所有声明、类型及必需输出先准备完整，再发布；命名发布失败清除本次输出并保留诊断。
- 已绑定数组输入要求本周期有效上游，失败不回退默认值；可选未连接输入才使用默认值，留空表示不提供，`[]` 表示明确空数组。每数组最多 10000 项，文本内容总计最多 262144 字符；默认值文本 4096 字符，严格要求 JSON 数值/字符串项，拒绝 null、混合及嵌套。
- 内联代码缓存标识纳入宿主模块版本，避免契约更新后复用旧缓存程序集。固定标量入口保留；旧 DLL 二进制兼容尚未集中验证，不声称任意宿主版本兼容。
- 六模块自带例程“脚本 · 数组逐项补偿（无需图像）”：测量数组 + 标签数组 → C# 加 Offset → 数组统计 / 标签取值 → 均值判定。检查配对长度与非空，返回真实数组；不自动运行、连接设备或发送结果。中文帮助覆盖操作、API、默认值与边界。

## 用户能看到和完成什么

- 原“更多→更多图像工具”改为“显示”一次展开的308DIP分组面板，视图、叠加、辅助分组直接可见。选择、平移、适应、1:1和ROI仍在首层；保留原控件、状态和处理器，不建立第二套图像状态。
- 显示面板不参与主布局宽度分配；普通动作和进入轮廓选择后收起，叠加/队列等选择保持可操作。Esc优先收起显示面板，不应用/放弃参数草稿。切到运行模式或关闭主窗时收起。
- 历史返回按钮独立于主工具行，避免窄窗挤掉常用按钮；历史只读等原守卫保持。
- 操作反馈独占图像底部一行，不再与像素Auto列争空间；下一行是中性短图层状态、当前画面ROI/屏蔽数量和像素。完整反馈、图例和像素保留悬停。
- 结果“已隐藏/全部隐藏”不写成无结果；ROI只数当前图像坐标的可见层，不混入其他图源。原逐层显隐、独显和全部显隐统一刷新短状态及完整悬停，防止旧路径恢复长说明。
- 原帮助同步“显示→图像队列”路径、右键平移、显示不删数据和Esc含义。不是新增算子或更换图像查看器。

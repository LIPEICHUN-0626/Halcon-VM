# S87 输入来源卡与当前模块连续试运行

更新日期：2026-09-03
Git 批次：新批次第 `3/10` 次；本轮不提交、不推送。

## 交付结果

### A 线：输入页改为任务式来源卡

- 双击模块后，中央 `输入` 页默认只显示来源就绪摘要，以及每个输入的状态点、名称、必需/可选、当前来源下拉框和当前值摘要。
- 端口类型、坐标上下文、消费者和失败诊断进入每张卡的 `详情`；批量恢复默认进入唯一的 `更多 · 批量输入操作`，默认均收起。
- 输入订阅入口改为按实时端口元数据生成，不再依赖历史工具种类白名单；当前 76 个目录工具共 116 个元数据输入端口均可进入统一来源选择和类型校验路径。
- 未新增永久顶部按钮。S83 的单击整卡拖动、双击打开中央配置、`18×16 px` 连接命中区、8 px 连线命中带，以及工具箱五个直达模式和 10 类就地折叠均保持。

### B 线：当前模块连续试运行

- 中央当前任务提供明确的 `试运行当前模块` 与上下文 `连续/停止`，节拍可选 100、250、500、1000、2000 ms。
- 启动时冻结本次参数草稿、输入绑定、ROI 和数值判定配置；每周期临时应用冻结快照，只执行当前模块，随后恢复已应用配置。
- 页面持续显示循环数、OK/NG/异常、最近结果和耗时；结果、图层、日志和异常使用现有真实执行闭环。
- 用户停止、顶部停止、切换模块、关闭中央配置、方案/流程切换、输入失效和执行异常会停止计时器并释放编辑锁。该能力不是全流程连续运行、相机连续采集、多流程或并行调度。

## A 线：配置与可见执行语义

参数窗输入页新增默认收起的“条件执行”：选择真实前序 Boolean 输出，默认真时执行，可切换假时执行。该端口使用真实 InputBindings，流程连接显示条件来源与真/假要求；普通输入卡不额外铺开条件字段。运行状态和日志显示“条件跳过”及原因。

示例菜单新增自带图像的判定驱动真/假路径：同一个数值判定 Passed 驱动滤波与增强，两模块分别要求真/假。主动载入，不自动执行；示例关闭遇 NG 停止以允许假路径到达，保留整体真实 NG。

## B 线：执行器中的条件判断

- 未连接条件保持旧行为；布尔条件与期望不符返回 SKIP，不调用该工具算法/脚本/设备逻辑。
- 模块进入执行前已清理自己的运行输出并失效下游；跳过不发布伪造结果端口，清理该模块兼容叠加。
- 显式依赖被跳过模块的下游跟随跳过，不复用旧输出；条件来源本身被跳过也跟随跳过。
- 条件无有效 Boolean、来源不存在/禁用/类型或顺序错误均报错，不能当作假。合法 NG 判定的 Boolean 可作为条件，执行异常不被当成有效判定。
- 复用原确定性范围、断点/单步、停止与超时处理；SKIP 不触发遇 NG 停止。结果汇总允许正常跳过，但原路径产生的 NG 不被抹去。
- 有条件的路径参数与文件阻断延后到实际到达该路径时处理；条件连接结构仍需合法。不会为了一个未执行分支预先调用其算法。
- 条件连接复用配方、复制/片段的 ToolId 重映射及撤销；真假选项为参数 DTO 新增可选字段，旧配方默认无条件。

## 真实边界

这是确定性顺序上的条件路径首版，不是完整 If/Else 容器、多流程、并行、循环或通用分支汇合。普通双输入工具若订阅任一已跳过来源会跳过，尚不能自动选择另一条路径。当前模块独立试运行沿用现有可用上游快照语义；流程全运行会清理上一周期输出。

后续 S101 聚焦类型化分支结果选择/汇合，必须只读取被选中的有效路径，不能用字符串或旧输出拼接冒充。全部新条件行为、UI、序列化与生命周期尚待集中验证。

本机原示例使用安装自带 `letters.png`、`Industrial_NoRej.omc`。真实执行首次在 `MainWindow.S81.Ocr.cs` 面积验证处失败：`HTupleInt64.get_DArr`。HALCON `AreaCenter` 返回整数面积元组，代码将其当作纯浮点数组读取。改为逐元素 `.D` 数值读取，保留有限/正面积验证和同序数量检查，不改变识别算子或阈值含义。

早期曾怀疑字库尺寸访问，诊断调用栈否定该判断；该试改已撤回，`Models/VmOcrValidationS133.cs` 无内容差异。不是字库算法、字体训练或模型资源重建。

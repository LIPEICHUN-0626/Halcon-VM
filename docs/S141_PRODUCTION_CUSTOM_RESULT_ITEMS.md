## 实读缺口与自然入口

`VmProductionRunLayoutData` / `VmProductionWidgetLayoutData` 当前只保存八个固定安全组件的标题、显隐与顺序，没有稳定 FlowId/ToolId/PortName 的自定义结果显示映射。`OpenProductionLayoutDesignerButton_Click`、`LoadProductionLayoutDraft`、`CaptureProductionLayoutDraft`、`ApplyProductionLayoutButton_Click` 与 `ProductionLayoutDesignerPanel` 是原真实草稿/预览/应用入口。`RefreshProductionRunView` 只镜像总判定、耗时、会话统计与最近步骤；`InspectionRecord` 没有当前周期 ToolId/RunId/正式标量快照。

正式实例端口来自 `ToolMetadata.GetInstanceOutputPorts`，已有动态脚本/JSON/子流程根输出；`TryGetOutputValue` 可取原始类型，但运行缓存没有 RunId，`RuntimeOutputVersion` 仅在清空时递增，不可冒称每次输出帧版本。S135/S138 已有根周期/步骤捕获边界及真实 Number/单位冻结；S138 不是生产卡映射，且只保存 Number，不能从摘要补造 String/Boolean。

## A 线：原运行页配置的单一按需结果任务

在原“运行页配置”面板新增一个按需“结果项”任务，最多八项，不增加主工具栏按钮，也不默认铺满技术端口。工程人员选择稳定 FlowId、该根流程的 ToolId 和正式 scalar 输出端口；允许 Number/String/Boolean/ResultCode。根 `SubflowCall` 正式输出可选择，不深入内部子流程跨作用域猜端口；不提供任意全局变量或格式化缓存文本绑定。

每项只有来源、标题和按类型出现的必要选项：Number 可设 0–8 位显示小数，其他类型不露无用数字框。单位来自真实明确合同/本次输出，自动显示；未声明即明确未声明，不让用户填 mm 或自行换算冒充标定精度。源模块禁用、端口消失/类型改变、Flow/ToolId 悬空都有短提示，不能按同名模块偷偷重新绑定。

默认无结果项时不增加生产卡；配置了属于当前流程的项才显示紧凑“当前周期结果”卡。默认聚焦值/标题/单位和缺失状态，RunId、算法定义、来源/页面等技术身份通过悬停或更多查看。运行中、尚未运行、来源非生产、失败/跳过/未到/无有效值与身份失效不能看起来像本次产品已经给出数值。布局草稿仅预览显示设置，不运行检测、不重判产品、不写通讯。

## B 线：独立的当前周期值级快照

新增正式、独立、只含值的当前周期显示快照，不扩写生产历史库、不重做 S138 趋势/SPC/统计，也不另建算法执行器。根 Full 周期被真实接受时固定 RunId、Flow/会话、算法定义及版本、来源、开始页面、模拟事实和本次显示映射；这些身份不从稍后 UI 状态或最后一条日志补造。仅明确生产页面、已知非模拟且来源为真实完整根 Full 的本次周期展示生产值；工程范围/F5/子流程内部/来源未知/模拟/图片批次不得伪装本次生产数据。

在同一真实步骤完成边界冻结正式原始 typed scalar，不直接持有工具缓存、HObject/句柄或 InspectionRecord 图像。只有本次步骤 OK/业务 NG、有明确有效当前输出及匹配端口类型才取值；业务 NG 是产品判定，不因 NG 自动抹掉有效测量。SKIP、禁用/未到、步骤失败/超时/停止、非有限 Number、超长文本、端口类型变化及捕获预算问题明确为缺失/不可用，不能补零、沿用上周期或解析 OutputSummary。业务提前停止时未到项必须注明，不把整行旧值当完成数据。

开始下一周期清空原显示值；完整周期收尾依本次明确终态发布冻结显示。异常/停止/超时不能被旧合格值遮住；工程/模拟执行也必须让旧生产结果失效或明确非本次生产，不用旧缓存继续显示。方案/Flow/换型/参数应用/输入绑定/ROI/资源/标定等实际定义改变，或显示映射正式应用后，使旧快照失效；不得从活动工程当前全局值重新“刷新”历史快照。运行过程中更换页面不改变被冻结资格。只读显示不产生新的判定、回传、报警确认或设备操作。

配置进入原布局草稿、应用/取消/重置、撤销/重做、配方/完整工程副本和复制生命周期；正式应用受 S137 工程授权/lease 及原真实忙碌保护。旧方案缺映射默认空，不插入教程/默认工具。Flow/工具复制应按实际新 ID 重映射；若本轮未实现该重映射，必须保留明确悬空且不能按名称重新绑定，不能默默指向另一流程的结果。最多八项、文本/字段/定义预算与截断/过长缺失均有边界；显示小数仅格式化，不修改原 Number、单位或下游值。

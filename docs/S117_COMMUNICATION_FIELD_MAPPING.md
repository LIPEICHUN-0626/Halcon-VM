# S117 通讯报文与字段映射任务

状态：代码已接入，部分实现（待集中验证）。S117 在原 TCP 客户端流程工具和统一参数窗上完成第一组响应字段映射路径，不宣称通用工业协议栈。

2026-09-28 接线范围：原高频区保留主机/端口、发送模板及是否等待响应，编码/行尾进入折叠“传输格式”；折叠“响应字段映射”可选不映射、分隔字段或 JSON 路径。最多各选一个 String/Number/Boolean 字段，空白选择不生成相应端口；参数持久化，实例输出端口随选择动态出现，仍可从下游真实订阅。原 I/O 页继续负责 {String}/{Number}/{ResultCode} 来源。一次运行后同一参数窗显示有界收发摘要，原始 SentText/ReceivedText 端口不删。

执行：复用原 TCP 单次连接/发送/接收/超时/释放服务（响应上限 1 MiB）。分隔字段用从 0 开始的索引，数值按不变文化有限数解析，布尔接受 true/false/1/0；JSON 路径复用 S110 严格 JSON 解析，要求目标类型真正匹配。缺字段、越界、格式和类型错误使本次结果 NG，错误指向字段；原始响应和连接/字节/耗时仍可见，不回退旧映射输出。映射模式必须勾选等待响应并至少配置一项。折叠“无设备试解析”以同一解析器处理粘贴的响应样本，只显示草稿结果，不联网、不修改运行输出或配方。

限制：每类当前只有一个映射槽，不是任意字段列表；不支持二进制报文、自定义校验、消息关联 ID、重试队列、长连接或 Modbus/串口协议。真实远端场景仍待集中验证。

A 线：在原通讯工具的统一参数窗以任务式卡片配置请求来源、发送内容和响应提取目标；默认只显示高频字段，原始报文、编码/行尾、异常详情按需展开。调试时能从一次执行直接看到发送/接收摘要，错误可定位对应字段，不增加永久顶部按钮。

B 线：在现有 TCP 客户端单次交换和类型化端口契约上增加明确的响应字段提取、缺字段/格式错误处理与可继续订阅的 Number/String/Boolean 输出，保留超时、连接释放、日志、配方及离线无设备学习路径。不引入未经要求的鉴权协议、不把文本拼装冒充工业协议栈。全部待集中验证，按完整 A/B 价值闭环实现。

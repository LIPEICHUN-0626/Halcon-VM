## B 线：三条真正有绑定、可修改和保存的组合项目

每个项目在独立新方案内创建正式节点和真实端口绑定，沿原加载确认/工程编辑保护/资源生命周期；最多三条推荐路径、单项目不超过十二个节点。旧示例目录继续保留。

1. **对象检测 → 条件判定 → 生产查看**：复用 S144 源图、阈值、对象分析、真实面积数组统计与数量判定，在此基础上接真实 `Passed` 布尔条件到后续正式模块的 `$RunCondition`，明确显示跳过/失败而不拿旧值。原生产布局配置本 Flow 的正式数量、面积或判定卡（最多八项，按实际端口类型）；切换运行模式及执行完整周期仍是主动操作。对象数/数组统计成功不等于产品合格，学习门槛不是出厂标准；证据默认关闭，不自动连接通讯或启用触发。
2. **NCC 明确选择 → 固定参考对齐 → 找边与覆盖判定**：复用 S131/S145 真实模板参数和选择、S132 固定参考、S143 搜索带与真实 Coverage 判定，绑定源 `Image` 到 NCC/对齐、NCC `SelectedPose` 到对齐、对齐 `Image` 到找边、找边 `Coverage` 到判定。用户必须在当前正式输入上训练并应用模板、重新运行、显式采固定参考、编辑搜索带；不预造模型/参考或用缺选零位姿。NCC 尺度为 1，对齐是刚体重采样，输出坐标与原图独立，原图 ROI 不能偷偷搬到对齐链。
3. **图像直线 → 同链像素端点 → 平面标定 → 世界距离判定**：复用 S143 正式 `KeptPoints` 接现有类型化点集拟合的 `Points`，由其真实 `StartPoint / EndPoint` 接 S124 `PointA / PointB`；标定 `Image` 必须绑定同一原图源。S124 `WorldPointA / WorldPointB` 接 S125 `PointA / PointB`，`WorldDistance` 接数值判定。用户明确采至少三个非退化的像素/世界对应点、填写真实单位并应用，再测量；不预造标定样本、比例或毫米结果。拟合端点距离表示所选边缘段的范围，不冒称工件尺寸/现场精度；需要稳定物理边界须自行设置搜索带/点域。

推荐项目补齐真实组合绑定和必要结果项，而非只增加说明文字。找不到图片、尚无模板/固定参考/标定、空对象数组、无有效线或绑定失效时，提示当前缺口并保留正式失败/缺值，不自动运行补旧结果。只读取正式类型化端口，不解析 Candidates、参数摘要或日志伪造值；沿既有对象/像素/数组/模型/时间预算，不为学习模式放宽安全边界。

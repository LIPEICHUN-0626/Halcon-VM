## 历史实现记录

部分实现，待集中验证。本轮未编译或验收。

缺失资源行已增加“重新定位”：用户主动选择图片或模板后，只更新本次捕获的导出 DTO，刷新缺失计数并解除继续限制；取消整个导出不改变活动方案。此处只判断文件存在，不宣称内容、模型版本或算法兼容已经验证。活动方案持久修复仍通过原模块参数完成。

导出范围页已接入：保存位置选择前显示实际图片/模板引用数、缺失数及逐项名称，路径在悬停说明中查看。缺失文件时禁止继续；显示当前方案中未打包的 HDevelop、脚本 DLL、资源库 DLL、OCR 模型和设备/运行库授权范围。范围页与实际导出使用同一份捕获的方案 DTO，不修改编辑中的方案。这是产品内资源保护逻辑，不是本轮开发验收。

最新范围：菜单导出已包含显式 ShapeModelPath 和兼容 TemplatePath，复制后改为相对路径，载入时按方案目录恢复；同一模板复用一次复制，资源缺失拒绝发布。菜单和资源清单明确说明排除 DLL/脚本依赖、OCR 模型及设备环境。当前模型中未发现本轮可直接映射的独立标定文件字段，未擅自宣称支持标定打包。历史下方“模型未包含”仅适用于最初图片版本。

A 线：文件菜单增加按需“导出方案及本地图像”，不增加主工具栏按钮。

B 线：导出独立方案 DTO，将本地图像复制到独立资源目录，JSON 使用相对路径；加载时按方案目录解析图片路径。原方案、源图片不修改。迁移需要同时复制 JSON 与图像目录；模型、脚本、DLL、标定等资源尚未纳入，不能称为完整工程打包。失败可能留下部分导出图片，后续需补事务清理、资源清单及完整外部资源路径支持。

续接已写入：同源路径图片只复制一次，资源目录生成中文清单；先暂存方案，资源齐备后才原子发布正式 JSON。发布前失败按本次创建路径清理，目录仅非递归删除；权限/占用导致清理失败时可能残留，不删除原图或以往导出目录。序列化临时流已纳入释放。仍未编译或验证，完整模型/脚本/标定资源打包待后续实现。

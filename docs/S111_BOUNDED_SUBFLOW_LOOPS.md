# S111 有界循环子流程

状态：2026-09-24，部分实现（待集中验证）。已在原子流程定义与执行器接入有界循环、逐项上下文和数组收集；统一参数窗、内部接口、执行跟踪、结果摘要及示例也已接入。未执行编译、回归、启动或鼠标验收，不能宣称已验证交付。下一 S112 多图像源任务工作区，见 `S112_MULTI_IMAGE_WORKSPACE.md`。

## A 线

统一参数窗按模式显示单次/固定次数/数组逐项；固定次数和数组来源仅在适用时可见。内部编辑代理新增当前项、索引和总数，预览首项用于连接；返回接口仅对 Number/String 提供逐项收集勾选。调用状态和跟踪路径附当前项/总数，默认结果优先完成数、计划数与累计执行步数，细项仍按需查看。零项、停止、失败消息明确说明返回和副作用。无新永久顶部按钮或第二套画布。

## B 线

复用原执行器，按实际顺序循环，逐项模式接正式 Number[]/String[]；普通调用输入在本次调用中保持，逐项字段每项更新，内部模块结果每项先失效再运行。普通返回只在成功结束时发布最后一次值；勾选收集后追加 `$Items` 数组端口，并保留普通端口以兼容旧连接。返回引用保护覆盖下游与上级子流程。零次返回空收集数组、完成/计划数和 HasLast=False；普通返回不发布。调用前读取并冻结本次数组副本，不将之后变量变化误用为当前项数据。

限制：一次调用最多 1000 项；数组超过 1000 项明确拒绝；累计根调用最多 10000 步；子流程调用深度仍最多 8。每项检查停止/超时和原 StopOnNg，断点/单步沿用原路径；不承诺中断单个 HALCON 算子。任一失败或中断清空调用返回，不发布半组结果，诊断记录已完成项数。变量/通讯等副作用不会自动回滚。循环模式/次数/数组输入和返回收集标记均进入原配方、复制与撤销；当前项/计数/调试记录不入配方。

无需设备的五模块示例：三件尺寸数组 → 逐项补偿与数组收集 → 数组统计 → 固定三次编号与收集 → 编号统计。中文帮助及手册已同步。实现涉及 `Models/VmSubflowModels.cs`、`Models/VmSubflowLoopS111.cs`、`MainWindow.S102.cs`、`MainWindow.S102.Editor.cs`、`MainWindow.S102.Trace.cs`、`MainWindow.S111.cs` 及原参数/元数据/UI/例程接线。集中阶段还需验证嵌套预算、空输入/零次、NG/断点/停止、数组所有权、收集引用保护、保存/复制/撤销和真实交互；编号不是验收证明。

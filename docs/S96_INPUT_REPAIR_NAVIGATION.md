使用路径：双击模块 → 输入 → 详情 / 来源修复 → 打开来源模块配置 → 修改/应用/试运行 → 返回 → 原端口继续配置。系统输入/不存在来源给出提示，不能冒充有上游可打开。

当前尚不是自动根因诊断或一键修复：需要用户主动判断真实诊断、选择参数，并决定是否执行。后续转入运行到来源与缺失输入的任务提示，与已有确定性调试计划衔接，不创建第二套执行器。

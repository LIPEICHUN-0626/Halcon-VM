## A：原颜色参数小窗更容易使用

- 原按钮明确为“从输入图像取色”。缺输入、上游未运行、灰度图、未应用输入/ROI来源或已知失效ROI时禁用，并就近提示原因；不靠点击后弹出错误框来解释前提。启用状态只读取已有元数据，不读帧、不计算HSV。
- 仍复用四项常用短字段与原“更多参数”。取样摘要压为一行，实际输入来源/尺寸或取样坐标/H/S/V详情悬停查看，不增加永久面板或改变流程布局。
- 新取样建议色相保留至0.001°，清除浮点尾数；接近360°的四舍五入回到0°，摘要与字段一致。已有配方/手填值仍按原精度读取，不全局改写参数精度。
- 手改色相、输入草稿变化或实际帧更换清旧取样色块；取样色块只是当前样本，不写配方。取样仍仅写原草稿，F5/应用/取消沿原路径。
- 原示例明确“原始红色覆盖比例判定”，帮助说明Region面积筛选与原HSV AreaRatio判定是两个分支，筛除小色块不会反改上游比例。低饱和点说明改为在“常用”设置180°容差，与真实入口一致。

## B：真实检测链与范围修复

复用原`color-coverage`四工具示例：RGB图像源→HSV颜色检测；其Region接区域特征筛选，其AreaRatio接数值判定。自有100×80 RGB图为绿色背景、600像素红块及4像素红块，不依赖外部设备或下载图片。

| 真实场景 | 结果 |
| --- | --- |
| 红色检测 | Area604，SampleCount8000，AreaRatio7.55%，两个区域 |
| 原区域面积筛选 | Area600；数值判定仍读原7.55% |
| 在原输入画面取绿点、F5草稿 | 色相120°；Area7396，已应用参数仍未改变 |
| 无匹配蓝色色相 | Area0、RegionCount0、HasMatch=false；算法OK不是业务合格 |
| 本地检测区减屏蔽 | 匹配500 / 有效700；实际Region下游500、比例判定通过 |
| 同链继承前序颜色Region | 匹配604 / 有效604，100% |
| 输入本身缩小有效域 | 匹配9 / 有效9，未扩大有效域 |

原HSV路径曾通过`GetBoundRoiLayers`静默过滤缺失/异源/无几何的绑定，过滤后可能以null域退回全图。本块在原有效域入口复用阈值绑定校验，并用于取色前提；缺失身份、错误坐标、全部停用明确拒绝，运行失败清旧输出。兼容边界：未绑定仍用输入有效域，继承模式仍忽略本地检测区、保留屏蔽规则，停用部分ROI仍按原规则排除；不把该校验扩至全部工具。Local模式即使留有被忽略的前序绑定，也不能绕过“全部本地ROI停用”判断。

## 当前已写入的 A/B 路径

A 线：原流程区标题旁提供紧凑当前流程选择，添加、重命名、复制和删除放入就地“⋯”菜单；命名使用短窗和唯一名称校验，运行按钮明确“当前流程”。切换先停止条件检查、确认模块草稿并逐级返回子流程，再沿用原画布和参数体系；运行/历史查看期间禁用选择。会话内恢复该流程的选中模块、缩放和滚动位置，不让新流程自动打开参数窗。

B 线：配方版本 3 新增稳定 FlowId/名称/Tools/运行策略/图层样式集合和当前流程标识，保存与恢复捕获全部流程，当前内部编辑合并回所属根流程。旧 ToolFlow 继续走原迁移，显式空列表保持空；新建空白流程无默认模块。缺失当前流程标识回到第一条，空集合、重复流程标识/名称及无效模块结构拒绝；未连接的工程草稿保留原来源诊断，不因尚未配好而禁止保存。

复制深复制参数、递归重映射模块、连接、数值判定、组合及内部返回来源；不复制运行句柄，图层样式使用新身份的默认值。切换释放当前工具/Shape 运行资源，清空图像队列、图像与调试指针/调用记录，目标流程等待重跑；旧流程仅停放纯配置，不会被其他流程直接读取运行输出。加载失败尝试恢复原流程定义。流程删除需明确确认、至少保留一条，当前不纳入模块级撤销。

ROI、DLL 与全局变量引用清单/删除保护扩至全部流程和内部调用，并显示流程路径；图像及 Shape 随行导出的范围与路径解析覆盖全部流程。会话内按流程保存模块编辑历史，共享 ROI/变量/DLL/生产布局指纹变化时不恢复另一流程的旧历史，避免回滚他处共享修改。图层显示配置按流程保存。

## 运行归属续接（2026-09-14）

普通结果记录已保存执行时的方案名、FlowId/流程名、当前方案打开会话和根/内部执行范围；流程重命名不改写旧记录。结果页显示“方案 / 流程”，CSV/XLSX 追加归属字段，原字段顺序保留。批次历史版本 4 追加 FlowId/流程名，历史列表和批次 CSV 可见；旧记录明确“流程未知”，不伪造迁移身份。

生产页的最近结果筛选当前方案打开会话、当前根流程和根执行记录；内部调试记录不混入。运行统计按本次方案打开会话内的 FlowId 分开，切换保留各自累计值，新建/重新打开重置会话统计，清空记录仍清空所有记录及会话统计。它不是持久生产统计或 SPC。切换/加载清空当前判定、耗时和可手动外发的旧结果缓存，执行状态与日志来源补当前流程名，现有对外 JSON 协议未擅自变更。

历史对比候选、趋势批次/端口和实际趋势点按同一 FlowId 限定；无 FlowId 的旧记录只在其原批次比较，避免仅凭同名工具或 ToolId 把不同流程拼为一条趋势。上述路径全部部分实现（待集中验证）。当前 TCP 收消息仅记日志，没有已有的收消息触发执行器入口，后续需真正建立目标选择、启停及忙碌处理，不能把日志回调当自动调度。

## TCP 指令触发续接（2026-09-14）

A 线：通讯页新增默认收起的“收到指令后运行流程”，包含目标流程、短指令、应用配置、显式启用/停止与状态说明；不增加顶部永久按钮。只保存 FlowId 和指令，启用态不写配方；打开方案、流程切换、断线/状态变化、通讯错误及用户停止均解除启用，目标被删除不会改跑第一条流程。原顶部停止同时停止触发。

B 线：现有 TCP 接收回调接入有界逐行分帧，支持 LF/CRLF、拆包和合包；指令为 1–64 个可打印 ASCII 字符，整行精确、区分大小写，不执行任意代码/表达式。接收行缓存最多 128 字符，超长丢弃到下一换行。匹配后在接收线程先占用唯一执行槽，防止 UI 队列形成延迟补跑；到达时已忙碌、重复匹配或超长指令丢弃并记录，不持久排队、不自动重试。

启用会显式切换并固定所选根流程、确认草稿、检查已连接及运行准备；真正收到指令时复查方案打开会话、目标、连接、编辑状态、参数/ROI/资源配置指纹和准备问题，再调用原确定性执行器。内部编辑/历史/连续/批次/当前模块试运行不抢占。超时、异常、用户停止或遇 NG 停止解除启用。沿用既有可选结果外发，不另加忙碌 ACK 或擅改 JSON 协议，不声称单个 HALCON 算子可被中断。

本入口仅适合受信任网络和设备，没有新增鉴权、加密、请求 ID 去重或持久消息队列；其他协议触发、并行调度、跨流程数据交换仍是独立缺口。代码路径部分实现（待集中验证），没有连接实际设备或运行验收。上节“TCP 仅记录接收”是接入前基线，现由本节覆盖。

## 用户目标

同一方案内组织多条独立检测流程，切换时清楚知道正在编辑和运行哪一条。完整路径为“空白新建 → 创建/命名流程 → 搭建与复制 → 切换并运行当前流程 → 保存 → 重新打开恢复全部流程”。不靠增加几个空白标签页交付。

## A 线：明确当前流程，保持工作区稳定

在现有流程区提供紧凑流程选择与当前名称；添加、重命名、复制和删除进入就地菜单，不增加一排永久顶部按钮。切换继续使用原模块箱、纵向画布、图像区和统一参数窗；先处理未应用草稿，不把旧流程图像、参数和结果显示成新流程的内容。保留各流程视图与选中位置，运行命令明确作用于当前流程。内部编辑先返回所属根流程再切换，不丢嵌套修改。

## B 线：真实方案生命周期与作用域

- 在原配方基础上保存有稳定 ID 和名称的多流程集合及当前流程标识；旧单 `ToolFlow` 明确迁移为一条流程，显式空列表保持空，新建不加载默认模板。
- 新建、复制、删除、切换、保存、另存和恢复使用同一真实数据路径。复制重映射流程/工具与嵌套引用，保留合法参数和资源，不复制运行句柄或结果。
- 首版只明确执行当前根流程，沿用确定性引擎和原调试语义；运行中阻止切换、删除等会破坏执行作用域的编辑。模块输入不跨根流程偷偷订阅；未知来源明确报错。
- 结果、调试指针、图像上下文、编辑历史与选择按流程隔离；共享 ROI/DLL/模板资源引用需覆盖全部流程和嵌套层级，删除不能破坏未显示流程。
- 配方保存包含全部流程，而不是只保存当前画布；加载错误、重复 ID、丢失当前流程和旧版兼容明确处理。失败不覆盖原方案。

实施先阅读配方、根方案捕获、S102 编辑栈、历史/资源与运行入口，再按真实依赖修改。模型、界面、执行和保存必须共同落地；不能仅新增集合便标记完成。

## 风险与范围

重点风险是切换造成未应用草稿丢失、只保存当前流程、旧结果串到新图像、共享资源误删和内部调用引用失效。保留原单流程读取兼容，增量扩展配方，不无故重写算法。跨流程数据交换、设备指定流程触发、并行调度和多相机同步不是此首版默认已实现项，需要后续独立闭环。

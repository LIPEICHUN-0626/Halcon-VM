# S131 NCC 灰度模板匹配

状态：2026-10-02 代码已接入，部分实现（待集中验证）。S111–S131 均待集中验证；未进行编译、启动、回归、渲染或鼠标验收。

A 线已接入：原定位分类新增“NCC 灰度模板匹配”，图像源直接连接 Image。双击统一参数小窗，“制作模板”默认折叠，读取输入后在窗内拖动整数像素矩形、后台制作独立模板。常用只有最低分数、最多候选两项，角度/重叠/极性/层数等进入更多参数；结果候选在同一“更多”内按需展开，选择候选会在模块输入图像显示十字，仅查看，不改变正式最佳 Point/Pose。保持同一草稿/F5/应用，不增加永久顶部按钮、不压窄主流程。

B 线已接入：真实 HALCON create_ncc_model/find_ncc_model/read_ncc_model/write_ncc_model，不是 Shape 改名。输入单张单通道 byte/uint2 Image，可选同链搜索 ROI；RGB 必须上游显式转灰度，不自动缩放或转型。模板原点为训练矩形质心、参考角 0°，Point/Pose、CenterRow/CenterColumn 使用 AffineTransPixel 转换后的真实像素中心，AngleDegrees 单位为度；候选框 XLD 使用原 HALCON 匹配矩阵显式变换。最佳候选按最高分数、同分原候选序号确定，查看别的候选不改变输出。正式端口含 MatchCount、HasMatch、Score、Point、Pose、位置/角度、训练参考点/模板尺寸、Candidates、ModelVersion、Parameters、ResultCode。

训练/草稿：读取按钮只可执行已经连接的 ImageSource，其他处理类上游须先运行；输入订阅草稿变化须先应用，不偷偷提交。读取预览持有独立 ImageCopy 与输入快照/来源版本。后台训练完成核对模块、输入版本、坐标、训练属性和停止态，失效/取消/失败不覆盖旧已应用版本；新版本仅进入当前草稿，F5 可直接试运行，不强制先应用搜索参数。界面矩形最小 3×3，必须完整在真实 domain 内且有灰度变化，最大 1048576 像素；单图最大 16777216 像素。取消在当前 HALCON 算子结束后生效。

搜索/结果：训练框不等于搜索 ROI，未设搜索区默认全图有效域。搜索 ROI/屏蔽限制模板参考点位置，不保证整个模板足迹在 ROI 内，也不等同于逐像素排除相关性；模板可跨范围边界。默认 MinScore=0.7、最多 1 个候选（上限 256）、最大重叠 0.5、起始 −180°/范围 360°、层数 0 自动、保持极性和亚像素。改变建模层数/极性须重训，搜索角度不得超出实际训练范围；搜索固定 10 秒超时。无候选是有效搜索结果：MatchCount=0、HasMatch=false、ResultCode=NG，Score=0 明确为无匹配哨兵，不是实际相关分数；Point/Pose/位置数值/XLD不发布。通道/域/模型/超时等异常清理本次输出和候选，不回退旧位置。

资源/复用：NccModels 下独立不可变 `.ncm` 版本、SHA-256 和实际训练网格/原点元数据保存在参数 DTO；每次训练/搜索独立读取并释放 HALCON 句柄，读取锁及哈希/模型元数据校验防止被改写资源。单模型不超过 512 MB。相对资源路径可重开，打包前后核对 SHA 后复制模型；保存/复制/撤销保留不可变资源引用，不共享可变句柄。模板允许跨图匹配，TrainingImageContext 是历史训练身份，复制不把它自动改成新来源；正式输出仍标记本次输入链，ROI 继续同链校验。旧版本保留供撤销/恢复，尚无引用感知自动清理。

学习：顶部“示例程序→定位·NCC 灰度模板”显式装载三步 ImageSource→NCC→Score 数值判定；使用本机实际 `fabrik.png`（已读取文件头确认为 8 位灰度），缺图须自选单通道图片。示例不预训练、不自动运行，用户主动读取、框选、制作后试运行；分数 0.7–1 阈值仅供学习。中文版帮助已同步模板/搜索区别、候选查看和资源边界。实现见 `MainWindow.S131.cs`、`Models/VmNccMatchingS131.cs`、`MainWindow.S131.Learning.cs` 及原元数据/参数/执行/图像/配方/项目/帮助集成；本机 API/官方约束核对不是算法验收。

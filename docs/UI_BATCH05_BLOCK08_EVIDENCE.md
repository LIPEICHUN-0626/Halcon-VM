# 第五批08：步骤记录窗口减负

2026-11-03；已验证实现（下述限定范围）。第五批8/10未Git，原提交0b4ccf8保持。不新增算法、日志平台或外部编辑架构。

## A：原窗口问题与改变

原步骤窗同时显示重复标题/副标题、跟随与搜索/复制/导出行、带边框的多行摘要卡和永久导航说明，挤占真正日志正文。

- 模块身份作为单行标题，完整名称悬停，不改ToolId、名称或显示归属。
- 跟随与弹性搜索保留；复制/导出进入单一“文本”菜单，不再常驻两个按钮。非空搜索才显示就近“清除”。
- 原状态摘要与定位/打开参数同排；异常优先短显，完整状态/异常悬停。默认说明转入原按钮提示，实际操作成功/失败反馈仍显示。
- 两页搜索无结果时单独显示提示，不把提示写入TextBox、快照、复制或导出正文。当前页空文本时禁用文本操作，切页恢复正确状态。
- 清除搜索只恢复原查看快照，不恢复跟随、不重新捕获导航权限。未改变500ms跟随、记录采集、200条精确归属、256Ki字符上限、通讯解析或执行路径。
- 中文帮助和手册同步，明确导出沿原选区优先/当前页文本语义，不冒完整历史。

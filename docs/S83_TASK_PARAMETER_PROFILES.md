# S83：直接工具目录、单击拖动/双击配置与 HALCON 阈值估算

更新日期：2026-09-01

## 用户问题

用户在实体操作中确认三项阻碍：模块单击就打开参数导致无法自然移动；连接点和连线命中范围过大、遮挡卡片拖动；工具箱先在小窗口选大类、再进入小类，增加不必要层级。

## A 线：恢复自然的流程编辑

- 普通单击只选中模块并可立即拖动；双击模块才打开中央配置工作台。
- 待连接状态仍优先：点击目标卡主体会自动匹配兼容输入并写回真实 `InputBindings`，不会误开参数。
- 端点命中区从 `38×26 px` 收紧为 `18×16 px`，可见圆点为 `8 px`；透明连接路径命中带从 `16 px` 收紧为 `8 px`。
- 左侧默认直接显示全部 74 个工具的 10 个折叠分类；`全部 / 常用 / 收藏 / 最近 / 片段` 是同层短入口，不再通过分类弹窗二次选择。
- 常用参数继续位于中央工作区，并为 15 类高频工具提供任务画像，避免通用表单机械截取字段。更多参数、输入、ROI、结果和帮助按需进入，不同时占满首屏。

## B 线：真实 HALCON 阈值估算

- 阈值模块新增“估算暗目标”和“估算亮目标”。
- 使用当前模块真实 Image 输入以及已应用的 ROI/屏蔽有效域，调用 HALCON 20.11 `binary_threshold` 的 `max_separability` 模式。
- 估算结果只写入参数草稿，用户确认应用后才改变配方；失败或陈旧输入不会破坏已有草稿。
- 测试样本得到分割阈值 `153`：暗目标范围 `0..153`，亮目标范围 `153..255`；应用并运行后输出 `RegionCount=387`，真实驱动 NumericJudge。

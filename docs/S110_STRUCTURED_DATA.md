## B 线：真实结构化数据链

JSON 读取可用本地文本或真实上游 String；连接后上游失败不回退本地。字段支持 Number/String/Boolean/Number[]/String[]，全部字段准备成功后再发布。组装须订阅全部真实字段，先完成整份文本再发布 Json/Length/FieldCount；不自动外发。字段稳定 ID 与参数深复制接入原保存、复制与撤销链；改名保留端口，已连接输入、下游或子流程返回引用保护删除/改类型。

路径采用 JSON Pointer 分段/转义：读取支持对象和从 0 起的数组索引，空路径读取根；组装只建立对象层级，完整数组作为叶字段，数字路径段仍是对象键。拒绝重复映射、组装父子冲突及重复 JSON 对象键。null 和缺失报错，空文本/空数组按声明类型保留；不把数字字符串转换为 Number。平台 Number 为双精度，不承诺任意精度。

容量：1–32 字段，路径 1024 字符/16 层，JSON 1048576 字符/32 层/65536 个值，单数组 10000 项，单文本及文本数组内容合计各 262144 字符。拒绝不完整 Unicode、非有限数字及超限，不截断。采用有界解析，不激活 CLR 类型、不执行文本代码、不把 `__type` 当作类型声明。语法参考 [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259)，路径参考 [RFC 6901](https://www.rfc-editor.org/rfc/rfc6901)；产品限制单独明确。

学习入口“示例程序 → 数据 · 结构化报文与测量结果（无需图像）”：读取产品编号/布尔判定/尺寸数组/标签数组 → 尺寸统计 → 五字段嵌套报文组装 → 下游读取均值/首项标签。中文帮助和手册已同步，装载不会执行、联网或发送。不是 JSON Schema、脚本沙箱、MES 或数据库。

## 当前接入与真实操作矩阵

A 线将原生产工具栏“上一张/下一张/范围选择/运行图片批次”收至一个仅工程可见的“图片调试”菜单；停止批次单独按需出现，仅在实际批次运行时显示且不被工程锁封。操作员默认关注解锁、整流程运行、连续、暂停和停止；状态栏小文字可打开保护窗，不新增常驻大按钮。以上为代码接入，未进行渲染或实体验收，不能宣称首屏已视觉验证。

| 操作 | 当前边界 |
| --- | --- |
| 查看图像/结果/周期/报警、停止/断开/取消 | 安全操作允许；报警确认仅已读、人工处置只留备注，只读 CSV 导出不是工程配置编辑。 |
| 未启用保护 | 明确显示兼容行为；启动仍为未命名空白，不自动载入最近方案。 |
| 参数/输入/ROI/流程/变量/资源/设备/通讯/保存配置修改 | 需有效工程权限；实际修改入口和异步返回复核同代 lease，不以控件隐藏代替检查。 |
| 操作员运行与既有流程选择 | 仅健康且定义/session/Flow 仍匹配已封存会话的完整根流程；F5、选中范围、子流程调试和设备手采不借生产页获得权限。 |
| 操作员显式 TCP 连接/监听 | 只允许与已封存 TCP 字段完全一致的既有配置，保留旧忙碌、连接代际与触发守卫；不授予手动发送/任意通讯写入。 |
| 操作员换型 | 仅正式 S134 路径，目标规范 path + 当次真实文件 SHA 必须明确批准，再沿原准备/身份/忙碌/事务守卫；文件变化需工程重新批准。 |

| 策略故障/换型双失败 | 坏策略拒绝编辑与新运行；工程解锁不解除原故障门禁或 S134 双失败保护。 |

B 线独立于配方保存本机策略：8–128 字符自设口令，无默认码；32 字节随机盐、PBKDF2-HMAC-SHA256 600000 次和 32 字节校验，全长比较。授权 5–120 分钟，单调 Stopwatch 控制有效期及每五次失败 30 秒冷却，UTC 仅展示；重启不恢复授权，Lock/到期/Reload/配置换代。未读取策略前拒绝编辑，缺文件明确兼容，坏/不可读/重解析策略 fail closed，不自动删除或降级。策略 JSON ≤64 KiB、schema 1、版本 1–1000000、批准最多 32 项；原子写入前再核对授权及受管文件身份，保存失败不保留成功授权。Snapshot 不公开盐/派生值，托管口令字符串不声称可安全擦除。

S79 手势、S102 实际子流程变更、OCR 浏览、原 TCP/Flow 例外、布局 Cancel，以及 S114–S133 人工资源/后台训练返回等已补相关门禁；S134 批准换型/S104 预配置触发沿原路径接入。未编译、未测试、未做完整权限覆盖审计，残留/异步/异常分支仍待集中验证。已配置受信任配方的通讯与脚本可能外部写入，保护不是 DLL 沙箱。服务不后台监控任意本机文件，Reload 读策略，Unlock/配置保存另复核文件身份；有本机文件写权限者仍可能绕开策略。忘记口令或策略故障须负责本站点的工程人员人工恢复可信站点备份，不提供万能码或自动无保护恢复。

## A 线：简洁锁定/解锁与明确拒绝

复用原模式/低频工程菜单，克制显示“操作员·工程锁定”或“工程已解锁”，按需打开工程解锁/保护设置，不新增永久大按钮。切换页面不等于授权：锁定时可查看原图/结果/周期/报警和停止，尝试修改就地提示需要工程解锁，不打开一堆无效配置控件。工程解锁后沿原统一参数小窗/流程/ROI操作；主动锁定、会话到期和重启状态明确，不能偷偷提交或丢草稿，也不抢停正在执行的HALCON步骤。

初次保护须工程人员明确启用并自行设置本地凭据，无默认密码/PIN、不在源码/文档提供万能解锁码；未启用保留现有开发行为并明确标“未启用编辑保护”。凭据忘记/损坏提供明确站点恢复说明，不自动降级为无保护。解锁失败、权限拒绝和锁定说明可查看，但不记录口令、派生值或明文秘密。

## B 线：站点策略与真实入口门禁

新增独立于配方、不能随导入JSON替换的本机站点保护策略和会话授权。凭据采用系统标准口令派生/随机盐、受管有界文件与原子保存，不明文存储；进程重启/重新打开方案不恢复解锁凭证。解锁有界失败节流/有效期，策略读失败必须明确拒绝受保护修改，不能靠切页绕过。初次启用、改凭据或关保护需要有效工程授权，不将用户自选弱口令冒称高安全认证。

使用统一命令策略，并在真正执行修改的入口复查，而非仅隐藏控件：菜单/快捷键/拖拽、模块参数应用/模板训练与导入、输入连接、流程/子流程/复制撤销、ROI几何、变量/脚本/DLL/资源、方案新建保存恢复、生产布局与设备/通讯配置等都按明确策略处理，确认框/异步返回后再核对会话版本。草稿可只读查看；保护启用后不能从残留窗口或异步回调发布旧授权下的新修改。统一列明允许/拒绝矩阵，未覆盖入口不能宣称完整权限保护。

操作员允许安全查看/停止及现有已配置生产操作：显式运行、原受控换型、已配置触发/设备确认仍满足原准备/忙碌/身份约束；手工通讯测试/写入、参数和资源修改不因位于生产页面而自动获得授权。运行受信任配方中的通讯/脚本仍可能有外部副作用，允许运行不是任意脚本编辑授权。权限不替代S134故障/换型中禁运行、S136状态门禁或设备协议守卫；“工程解锁”也不能解除真实故障保护。停止始终允许。

主动锁定前沿原草稿确认，在授权还有效时由用户明确应用/取消；取消锁定应明示，不能悄悄丢修改。到期/恢复锁定则冻结进一步编辑，等待安全边界收敛或用户处理草稿，不自动应用、不中断单个算子、不重启/重连/重写。回调仍持旧授权版本的模型训练结果不得在锁定后自动发布，失败保留旧应用定义。工程身份/授权状态可作为今后事件补充，但不追改历史S135/S136事实或冒称企业实名审计。

完整路径：站点显式启用保护→操作员安全运行/查看→修改被明确拒绝→工程显式解锁→原工作流编辑/应用/保存→草稿处理后锁定/到期→新会话仍锁定。只提供本应用内误操作保护，不是Windows权限边界、可信DLL/任意本地程序安全沙箱、文件加密/防篡改、企业账户/AD/权限签名或硬件安全系统；有文件写权限/受信任扩展的用户仍可能绕开本机策略，应如实说明。

# S98 流程片段复用与边界输入

状态：代码已接入，待集中验证。本轮未运行编译、回归、启动或验收。

A 线：有外部输入的片段插入前显示紧凑的来源选择页，每个边界输入一行，标明目标模块、端口、类型和必需/可选。用户可自动选择、指定插入位置之前的启用模块输出，或不指定来源。没有外部输入的片段不增加确认页。空白方案可以直接插入，无需先创建占位模块。

B 线：选择写入原粘贴后处理路径，在同一次片段撤销记录中应用，保留内部 ToolId 重映射。明确指定来源采用现有绑定校验及双输入重复来源限制；不合法时不偷偷替换为另一个来源。未解决必需输入继续进入现有问题清单。取消选择不插入；运行/历史状态阻止插入，未应用草稿先确认。

不指定来源不等于强制禁止系统输入：Image 等既有默认语义保留。片段仍为线性流程复用，不是执行型子流程；文件/模型路径沿用既有片段内容，不宣称跨机器资源随片段打包。尚未验证所有输入组合、撤销、取消及 UI 操作。

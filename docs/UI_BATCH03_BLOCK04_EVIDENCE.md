## 实际改动

- A：原ROI任务中图层名称可直接点击，在正在编辑模块的输入画面中选中，复用原控制点、原图层选择与数值编辑器。原短摘要明确模块名；勾选仍只改本模块绑定草稿，角色/状态/共享图层几何含义放悬停说明。没有新增常驻面板、第二编辑器或改变流程布局。
- B：所有支持ROI的模块加载绑定草稿时保留缺失ID，并优先置顶，不能因应用其他参数静默丢弃。缺失项可明确解绑，解绑草稿取消恢复，明确应用后才移除；缺失项不能重新勾选成为有效图层。HSV与普通阈值的全部停用检测区在参数校验阶段也明确拒绝。
- 名称定位核对当前真实行/图层实例、活动编辑模块、忙碌/历史、输入草稿与坐标。未完成绘制或数值草稿须先处理，不静默丢弃；锁定只读、隐藏不自动改可见性。定位不写绑定、不应用参数、不执行算法。共享图层几何原有应用/撤销语义不变，模块参数取消不会撤回另行应用的几何。
- 原中文帮助补充上述实际操作，不声称这些细节是海康官方实现。

## 中间失败与边界

- 初始测试把离散圆面积手估为81减9=72，实际HALCON圆为80减9=71；改用独立HALCON算子生成期望，半径3差集为23，未修改产品算法迎合估计。
- 测试曾直接修改已关闭编辑对象的定义，再打开其保留草稿，导致断言看不到新注入ID。诊断确认正式ID已增加而旧草稿未重新加载；测试改为明确加载注入的异常定义，不强制覆盖产品保留草稿，不把此测试设置错误当产品修复。
- 本块实证圆形与矩形屏蔽、原数值编辑取消/应用及同链继承。实体拖动、所有形状/位置修正/双视口/全部工具和子流程、设备与旧配方广度未全证。通用缺失行逻辑的实际运行验证集中于HSV与阈值，不冒全部算法验收。

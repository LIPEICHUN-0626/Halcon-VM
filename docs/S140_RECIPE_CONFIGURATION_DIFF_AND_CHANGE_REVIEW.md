## 实施前计划存档（历史）

## 实读缺口

当前 `RecipeChangeoverWindowS134.xaml/.cs` 只有当前准备、目标文件/根流程、静态问题清单和确认换型；`MainWindow.S134.Changeover.cs` 已冻结目标文件 SHA/定义/流程、执行准备与事务换型，但没有当前→目标的字段差异。`VisionRecipe`、`VmProjectFlowData`、`VmSubflowData`、ROI/全局变量/资源模型已有稳定身份；S138 稳定定义键只能分组，不能说明具体改了什么。文件不同或名字相同都不能替代真实差异，更不能证明运行环境就绪。

## A 线：原换型/准备窗的按需审阅

复用原低频换型/准备窗，增加紧凑“当前 → 目标”的配置审阅，不新增永久主按钮、不改变纵向流程尺寸/参数小窗状态。默认只列新增/删除/改变/未知计数和少量重点；逐项参数/绑定/资源细节通过所选项的一个更多区域显示，当前值与目标值并排、单位与模块身份明确。准备问题与配置差异按需切换，不同时铺满技术清单。

算法/执行配置与图位置/分组外观/图层样式等显示变化分列；不能让一次纯拖动淹没关键参数变化。显示“当前已应用定义”及目标文件身份/所选根流程；未应用草稿另有提示，不暗中纳入正式当前定义。无目标、旧身份失效、缺身份/重复身份、预算截断和资源字节未知均有明确状态，不以“无差异”隐藏无法比较。查看差异不应用草稿、不切型、不打开旧文件、不运行算法或设备。

## B 线：冻结定义、稳定身份与只读差异

实现纯只读值级差异服务，接收脱离活动状态的当前已应用定义和目标预览定义；不接触 HObject/句柄、设备、文件执行或外部 DLL。读取全部根流程及嵌套子流程，以稳定 FlowId/作用域内 ToolId/RoiId/VariableId/ResourceId 对齐；缺失/重复/歧义身份明确拒绝确定映射，不按名称或列表位置猜同一模块。旧单流程按其原兼容语义处理，不能虚构新稳定 ID 把未知当确定。

比较真实参数、工具启停/执行顺序/断点、输入绑定与端口/数值判定、子流程接口/循环定义、ROI 几何/角色/订阅坐标、变量定义/默认值、脚本代码/入口/接口、资源路径/声明 SHA/版本、相机与通讯配置、标定内参/点样本/单位和正式模型元数据。所有新增/删除/改变都能落到稳定对象和具体字段；运行中的变量当前值、图像游标等只有经实读证明是纯运行态才排除，变量默认值/设备路径不能误删。未知新字段保留并标明，不靠旧白名单漏掉算法变化。

显示变化单列真实 GraphX/GraphY、组折叠、图层/十字/生产布局等；名称变化只是该稳定对象的名称变化，不等于删除重建。路径/SHA/声明版本分别比较；缺 SHA 时即使路径相同也只表示配置文字相同，资源实际字节仍未知。差异本身不偷偷重新哈希任意路径、不 LoadFrom/执行 DLL，不把声明 SHA 相同当算法/安全/许可/设备可用。

使用有界行数/字段文字/嵌套深度/定义字节预算，超限须明确“不完整”，不把截断结果当无变化。脚本源码/长数组/样本等细节按需查看，默认简短摘要；不输出工位策略/口令。冻结当前会话/已应用定义与目标规范文件路径/文件 SHA/解析定义/Flow 身份，异步发布前后复核；目标重选、Flow/当前定义/会话/授权策略或文件变化使旧审阅失效，不能让旧报告为新换型背书。

差异只服务审阅，不实现自动应用、字段局部合并、恢复旧运行态或设备 I/O。确认换型继续走原 S134 的静态准备、真实忙碌/草稿/文件定义复核与事务应用/原路径回退；S137 正式批准及工程 lease 不因“已经看过差异”而绕过。只读查看不等于编辑授权，配置相同/文件 SHA 都不是设备连通或产品合格证明。

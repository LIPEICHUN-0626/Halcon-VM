现有 `BeginProductionRunS135` 直接对完整 `CaptureRecipe` JSON 求 SHA，没有稳定算法定义归一化；变量当前值、逐帧游标/图像路径等纯运行或显示态可能使每帧键变化。既有 `RecipeDefinitionSha256` 必须保留为当时原始快照事实，不能为聚合改写其含义。S138 新增明确有版本的稳定算法定义键，先实读捕获字段及其真实用途，才排除纯运行/显示态；不能笼统去掉“路径”或“变量”，图像源目录配置、变量定义/算法依赖、参数、订阅、ROI、设备配置、资源/模型 SHA、脚本、标定与单位变化必须保留。当前选中图像/游标等运行事实另留当时值，不丢证据；未知字段保守保留/不聚合。旧记录不伪造回填新键，也不混入新键组。

## A 线：原周期记录内按需趋势

复用原生产周期查询入口，在同一按需工作流中增加“趋势/过程”查看，不新增默认顶部大按钮、不压窄纵向流程或铺满生产首屏。默认只显示当前定义/Flow、明确样本范围、本次范围的有效数量和耗时趋势；关键 Number 通过一个就地来源选择进入同一图表。缺数值、旧记录、模拟/工程、截断或损坏记录用短提示说明，不画成零值。

提供明确的生产/工程范围、冻结定义/Flow、时间或最近 200/1000/2000 周期选择；工程调试和模拟范围必须另选，不能混在默认产品统计。选中趋势点可返回同 RunId 的周期事实和原步骤明细；当前身份仍精确匹配时才沿原入口定位模块，否则只读历史，不按名字猜当前模块。异常/普通产品 NG/STOP 分列，不用一条红色曲线把所有事实统称坏品。

## B 线：真实周期 Number 快照与有界统计

在 S135 原根 Full 周期/步骤边界追加可选、独立的类型化 Number 快照，兼容旧记录缺失字段，旧记录仍可查看耗时。只读取实际执行的本次步骤、正式实例输出元数据和当前有效数值；同 RunId/步骤状态或输出版本无法证明时记缺失，不消费旧帧、跳过分支或失败后残留端口。业务 NG 下仍有效的本次测量可保留，运行 ERROR/STOP/TIMEOUT 则保持独立状态。快照是值 DTO，不持有 HObject、图像、ROI 或算法句柄，不扩大执行范围、重跑步骤或外发。

冻结稳定 ToolId、端口名、工具/端口显示名、有限数值、已知单位/数值语义及有效性。动态端口按真实实例契约处理；未知单位明确标记“单位未声明”，不能猜成 mm/px 或自动换算。记录每周期/每步骤数量与文本上限，并保留截断标记，继续原单记录/目录预算；持久化和读取均不能把缺失变为有效零。

生产资格必须来自执行时明确冻结的来源/页面/实际模拟状态，不从 `SourceLabel` 或日志文字推断。默认产品范围只收明确的生产根 Full，工程/Debug/Unknown/ImageBatch、模拟及资格未知分开；旧记录缺模拟事实时不得补称真实设备。未保存定义、未应用草稿和截断范围明确提示或独立筛选，不静默混样。正常完成的 OK/业务 NG 可用于本范围合格统计，ERROR/TIMEOUT/STOP 另列且不混入坏品率分母；未保存成功的周期不凭界面缓存冒称历史全量。

序列分组以执行时稳定算法定义键及其版本 + FlowId + ToolId + PortName + 单位/语义为准，原始快照 SHA 另供事实查看，不用名称/路径混合定义或强行聚合旧记录。算法参数、订阅、ROI、设备、资源、脚本、标定/单位或端口身份变化拆开；只有明确同组的有限数值计算样本数、Min/Max/Mean/波动和耗时摘要，计算溢出必须说明不可用。图表最多 2000 周期，缺失点保留间断；范围不足/读取预算/坏文件/数值截断显示警告，窗口统计不冒称完整产线历史。

复用原有界本地周期库读取，不引入数据库、持续全量扫描、额外采图或后台自动重放。筛选和导出冻结同一值快照，CSV 继续 UTF-8 BOM、全字段转义及公式防护，并保留 RunId/定义/Flow/来源/有效性/单位。趋势查看与导出不修改配方、当前判定、生产计数、报警或权限状态。

## 用户路径与边界

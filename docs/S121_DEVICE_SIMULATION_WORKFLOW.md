# S121 设备模拟与通讯调试工作流

状态：A/B 代码已写入，部分实现（待集中验证）；未执行本轮编译、回归、鼠标验收或真实设备联机。S120 同样待集中验证。

已写入：TCP、Modbus TCP、RTU 原参数窗按需切换离线模拟/真实设备；样本文本/帧进入原草稿、配方与撤销路径，缺失样本阻断并清空旧输出。模拟运行复用现有 TCP 字段映射和 Modbus 帧解析，发布原类型化值以及 `IsSimulation`；Modbus 结果保留请求/响应帧、尝试状态和解析错误，可被数值/文本下游订阅。真实模式默认不变。方案通讯任务汇总、卡片连接状态和运行摘要明确标出模拟，不把 `Connected=false` 误称为设备在线。

隔离边界：包含模拟通讯的执行范围在运行前进入模拟语义；同范围真实 TCP/Modbus、相机采集、C#/DLL/HDevelop 与全局变量写入被拒绝，自动结果外发和“发送最近结果”被禁止；根步骤记录标记 `Simulation`，不进入生产最近结果/会话统计。图片队列仍可逐图调试，但模拟批次不保存生产追溯。单模块模拟只解析内存样本，绝不打开网络/COM。不能用模拟成功代替现场设备验收。

A 线：在原通讯任务配置与结果区域按需切换“离线模拟 / 真实设备”，默认仍为真实设备且显示醒目的模式身份；把请求、样本响应、解析值和错误组织成一条短调试路径，不新增顶部常驻按钮，不创建第二套参数窗。切换模式与草稿、配方、撤销、当前模块/全流程运行及日志保持一致，避免学习帧解析与真实执行之间断层。

B 线：复用现有 TCP 文本映射、Modbus TCP/RTU 帧解析，让用户提供的离线样本经原模块的类型化端口输出并能驱动后续数值判定/文本计算；模拟绝不能打开 TCP/COM、发送报文或触发生产外发，且不得把样本输出混作已连接设备。缺失/错误帧给明确 NG 与清空旧结果；模式保存在配方并明确标识。先读现有服务、配置/执行器和示例入口，再实现，不复制协议解析器。集中验证前仅标记部分实现。

完成边界：真实设备故障注入、硬件联机、PLC 安全验收、长期设备仿真和跨协议统一数字孪生不属于本块。

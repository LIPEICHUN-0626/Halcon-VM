# S113 双来源任务对比与成组检测

状态：A/B 代码路径已写入，部分实现（待集中验证）。S112 已提供同一流程多个本地图像源、单画面指定来源和按坐标链筛选图层；本次补双视口任意来源与按同名文件成组运行。并非相机硬件同步或并行调度。

已接入：左画面原输入选择框扩展为系统输入、当前模块各 Image 输入、当前模块 Image 输出、各指定图像源；右画面继续使用 S112“画面来源”。左右各显示来源、尺寸/SN、待运行/异常与独立像素读数，叠加和 ROI 图例按各自坐标链。双源配对入口藏在图像队列的按需区域，选择两个不同且已启用的源模块及两个目录，以文件名去扩展名作为不区分大小写的组键；重复键、缺任一侧图片或超过 1000 张阻止建立错误列表。可预览选中组两路真实源模块（不运行下游），可运行当前组或全部组。运行前重新校验源、目录、流程和文件存在/可读；含双图差分/动态阈值融合模块时还校验尺寸、通道和 HALCON 像素类型。每组仅在本次执行中覆盖源模块的文件与 SN，不修改方案参数或真实 InputBindings；记录组键、两条原图路径、两源 ToolId、结果码、异常和逐工具结果到本地批次追溯。示例程序给出“图像 · 双源配对与绝对差分”，两路默认同一 HALCON 演示图，参考路先平滑再差分，现场应替换为真实成组图片。

风险与集中验证边界：双源组追溯目前保存路径和逐工具结果，不伪造只含单图的历史图像快照；旧单图批次仍沿用原路径。需集中验证源目录变化、热切换/停止、不同尺寸/位深、异常源、Trace 恢复、双视口叠加与内存释放。目录配对按当前扫描快照运行，外部文件被增删后须重新检查；运行前会重新验证目标文件是否仍可读。当前未逐轮编译或鼠标验收。

## A 线：双源对比的紧凑任务入口

复用现有单/双视口和图像来源区域。双视口开启时，左右可各自选择真实图像源或当前模块输入/输出，选择项按需出现，不新增一排永久来源按钮。每侧显示实例名、文件或 SN、尺寸和待运行/异常状态；空图不借用另一侧。ROI、结果层、像素值和缩放联动遵守各自真实坐标上下文，切换不压缩流程区，不改变单击拖动/双击参数窗口习惯。

## B 线：成组输入与运行

提供两路关联图片作为一个检测组的明确导入/配对规则、预览和运行入口。组身份贯穿两图来源、双输入工具、记录/异常和保存；缺图、重复键、尺寸或位深不兼容必须可见且不运行错误配对。沿用真实 Image 端口、现有确定性调度和 HALCON 算子，不另造仅供显示的影子流程。给出不依赖硬件的双源检测例程，说明从导入、绑定、调试到结果的完整路径。

本块不宣称多相机同步、并行采集或跨源自动坐标标定。开发阶段代码接线后标记“部分实现（待集中验证）”，不逐轮编译、鼠标验收或频繁推送；集中阶段再验证配对顺序、不同尺寸/位深、断流、ROI/图层隔离和旧方案兼容。
